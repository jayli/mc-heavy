02帧序与线程边界

版本协议

  • 任务带 (columnKey, version)；blocks/meta 变更即 version++
  • 回包版本不符 → 丢弃 + 重新派发
  • 上传排队期间版本变了 → 同样丢弃重发
  • LIGHT 另校验输入集合：3×3 新到达就绪列 → 整体重算
  • 纯 blockEntity 写不 bump、不 remesh

帧预算

档上传预算每帧 mesh 下发
high ≥120Hz3 ms64
low 60Hz6 ms128
  • 判档：120 帧窗口内快帧（<11ms）比例 ≥5% → high，=0 → low，判一次锁定
  • meshUploadPerFrameLimit 默认 0；?chunkpace=N 可调

09红线

  1. 一份权威：主线程 typed array 体素；网格 / AO / 光照全是派生
  2. 无预生成：seed 确定性生成，存档只存 edits diff
  3. 重计算在 Worker：GEN / MESH / LIGHT；主线程只做输入 · 物理 · 调度 · 上传 · 渲染
  4. 单一 meshing 管线：面剔除在 mesher 内部；无独立 FaceCulling / consolidation / 地形 InstancedMesh
  5. 发布粒度 section 16³：三通道 BatchedMesh + 三级兜底
  6. 体素 DDA：禁止对地形 mesh 用 THREE.Raycaster
  7. 版本协议：(columnKey, version) 不符即丢弃重发；无 epoch / 防抖 / staging
  8. 同构纯函数：gen / mesh 无 DOM 无 three，两条路径同一份代码
  9. WebGPU 唯一后端：不做 WebGL2 降级
  10. Worker 相对路径 import：不继承 import map，禁止 import three
  11. 光照：skylight 垂直不衰减 + 水平每格 −1；快路径只升不降；shade 走顶点 float varying
  12. 物理手感：onGround 自动上台阶 MAX_STEP = 1.0

资源 URL

  • src/** 一律经 resourceUrl()（模块 URL 上溯两级 = 仓库根）
  • 根目录 HTML 用 ./ 相对路径（按文档基址）
  • 禁站点根绝对路径 /assets/…：子路径部署会 404
