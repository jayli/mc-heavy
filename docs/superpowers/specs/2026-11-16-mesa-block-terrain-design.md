## 1. 意图与为什么

**用户目的（原话）**：「给现在单调循环的地形增加一些多样性，目的很纯粹，就是引入一些不一样的地形，
不管用什么方法，只要很好地跟现有的地图 map 接壤就可以。」

现状世界的多样性瓶颈有实测依据（调研报告 §1.1）：`noise()` 是 sin+cos，coarse `0.08` 与 fine `0.02`
的公共周期 = **628.32 格**，biome 的 `TEMP_SCALE=0.01` 周期恰好也是 628.32 格。实测平移 628 格后
**高度逐格相同 89.3%、biome 一致率 87.3%** ⇒ 走 628 格就看到几乎重复的世界。

**本轮的解法不是「换掉全世界地形」，而是「嵌入一块不一样的地形」**：在南方第一个高台地带的
南侧放一块 800×800 的区域，内含三个互相接壤的地貌（平顶桌山 / 下切河谷 / 恶地层脊），
**块外世界逐位不变**。

### 为什么选这三个地貌

调研报告 §2.2 列了六类纯 2D 可迁地貌。本轮只取第 1 项 `region/club` 的三条子样条，理由是实测的：

| 候选 | 落差 p99−p1（现状 26） | 结论 |
|---|---|---|
| **club 三地貌** | 26（同级，但列内极差从 9 → 31 格） | **取**：唯一「运行时几乎免费 + 锚点全活 + 真出现崖壁」的 |
| spade 双层梯田 | 56（2.2×） | 不取：4.1% 的格 ≥35 会撞云层/空岛，需新增避让规则 |
| heart 丘陵 | 13（**低于现状**） | 不取：单独迁会让地图更平，与目标相反 |
| diamond 湿地 | 12（**低于现状**） | 不取：同上 |
| 沙丘 | 沙漠 p99 8→10 | 后续增量：幅度 >4 时废弃堡垒选址成片失败 |
| 丛林石柱 | — | 不取：原版门控通过率 0.0035%，照搬等于不生成 |

## 2. 目标 / 非目标 / 反目标

### 目标
1. 世界南方出现一块 800×800 的三地貌区域，三个地貌互相接壤，且与宿主高台地带接壤。
2. **块外世界逐位不变**（高度、biome、结构锚点、既有测试的冻结数字）。
3. 水面 / 海面 / 湖面逻辑**完全沿用现状**（用户 2026-11-16 裁定）。
4. 接缝可走（`MAX_STEP = 1.0`），不出现垂直断崖墙。

### 非目标（本轮明确不做）
- **块内地表材质分区**：`getBiome` 仍是现状噪声 ⇒ 台地上可能铺 sand、恶地脊上长草。
  用户 2026-11-16 裁定「没问题，先这样」。
- **块内植被/结构避让**：巨树 / 杜鹃 / 撒布仍按现状规则在块内落点，可能长在陡崖上。
  用户裁定「也没问题，有问题后面再单开一轮修复」。
- 全局地形替换、地形风格开关、`biome_parameter` 升级、大陆度基座、3D 密度场。
- 其余五类地貌（spade / heart / diamond / 沙丘 / 丛林柱）。

### 反目标（做成了也算失败）
- 块外任何一个格子的高度变了 ⇒ 既有 8 个 spec / 21 个单测的冻结数字失效。
- 既有结构（大竞技场 / 废弃堡垒 / 围场 / 浅水高台）**召不出来**（返回 null）。
  ⚠️ 「移位」可接受，「失败」不可接受 —— 两者必须分开断言。
- 块压到另一座高台地带或城市，削掉它们的缓坡 / 过渡带。
- 为了省事去改水面判据、阈值、门控或体素水填充规则。

### C1 的必要澄清（载荷性，勿误读）

`ocean.js` 的 `getTerrainHeight` **不是调用** `generateHeight`，而是它的**同构副本**
（TSL 里自己算 sin/cos，常量从 `TERRAIN_HEIGHT_PARAMS` / `BIOME_PARAMS` 读）。
所以「水面逻辑不动」**不等于**「TSL 那段高度输入也不动」。实测（39.8 万点，排除城市 bounds）：

| 口径 | 两侧判据一致 | 陆地上冒假水面 | 真水失去水面平面 |
|---|---|---|---|
| 现状 | **100%** | 0% | 0% |
| 换地形 + TSL 保持现状公式 | **89.1%** | **6.89%** | **4.01%** |

⇒ **本轮必须把 TSL 的高度输入同步成新公式**，这属于「沿用现有水面逻辑」的必要部分。
水面的**判据、阈值 `SEA_Y`、五点取样 ±3.5、城市门控、湖区门控、体素水填充规则一字不动**。

## 4. 方案取舍（Approaches）

### 方案 A：全局替换 `generateHeight`（调研 §6.2 的推荐路径）
四族 region 重写高度公式，k=2/K=80。
- 实测：落差 72.4 格（2.4×）、GEN 0.036 ms/列、零越界。
- **否决理由**：40 个消费方的标定值全部要重测；旧存档 edits 落到新地形上；
  且实测**不保留 biome 压平时大竞技场掉到 1/8 seed、废弃堡垒 3/8**。属产品级决定，超出「增加多样性」的诉求。

### 方案 B：共存 —— 噪声阈值切「台地区」，与现状地形混合
用 Perlin selector 阈值划出台地区（占 25%），边界余弦混合。
- 实测（8 seed）：最忙视域顶点 **+6.1%**（混合带 64 格）、section +8.1%、GEN 0.69 ms/列、
  迷你地图 **0.31 → 1.91 ms**；硬切边界会造出 **62 格垂直断崖**（不可用）。
- **否决理由**：仍需 `temperature`/`vegetation`/`selector`/`erosion` 四套噪声 + 值域标定 +
  水平尺度 k 标定；迷你地图主线程成本涨 6 倍；台地区遍布全世界 ⇒ 影响面无法收敛。

### 方案 C（**采纳**）：单块嵌入 —— 固定矩形 + 三条横向条带 + 界外零改动
块位置由「南方第一个高台地带」派生，块内三条带各跑一条子样条，块外矩形早退。

**为什么它最省**（实测对比，全部是同一份探针的单变量对照）：

| 项 | 方案 B 共存 | **方案 C 单块** |
|---|---|---|
| 需要的噪声 | temp / veg / selector / erosion / ridge / lower / hmul | **只要 ridge + lower_tier + badlands** |
| 分区机制（ti/vi 两层样条） | 要 | **不要** |
| 水平尺度 k 标定 | 要 | **不要**（块内坐标重映射，§5.3） |
| 单次高度求值 octave | 16.9（完整 club） | **3.47 / 3.69 / 5.47**（三条带各自） |
| TSL 五点/片元 octave | 54~119 | **17~27** |
| 水面遮罩是否要改高度图纹理 | 需要评估（调研 §5.D 出路 A） | **不需要**，直接同构翻译 |
| 块外顶点 / section | +6.1% / +8.1% | **0.0% / 0.0%** |
| 既有锚点 | 需重标 | **48 个里 45 个逐位不变，3 个移位，0 个失败** |
| 迷你地图（块外） | 1.91 ms | **0.293 ms（不变）** |

## 5. 设计细节

### 5.1 块位置：南方第一个高台地带 + 避让搜索

**「南方」= +Z**（与 `minimap-regions.js` 的「j 随 z 增大 ⇒ 上北下南」同口径）。

**宿主选择规则**（确定性，无随机）：在 `rx ∈ [-8,8] × rz ∈ [1,8]` 内取 `isTarnZone` 为真的 region，
排序键 = `rz 升序 → |rx| 升序 → rx 升序`，取第一个。

**首选矩形**：宽 800、高 800，x 居中于宿主圆心，`minZ = 宿主 cz + TARN_ZONE_RADIUS`（= 紧贴南缘，接壤）。

**避让搜索**（必须有，实测 5/12 seed 首选位置不安全）：
- 候选顺序：先沿 x 平移（步长 100，先负后正，保持紧贴南缘），再沿 z 南移（步长 100）。
- 接受条件：
  - 与**其它**高台地带圆的净距 ≥ 32（`CITY_TRANSITION_SIZE` 同口径，红线 1 不另写字面量）
  - 与城市 bounds 净距 ≥ 32
  - 与四个既有结构占地（大竞技场 ±42 / 废弃堡垒 ±53,±54 / 围场 ±20,±39 / 浅水高台 `SHALLOW_TARN_OUTER_RADIUS`）净距 ≥ 32
  - 与**宿主**地带净距 ∈ [−40, 120]（负 = 接触/浅重叠算接壤；> 120 就不算邻居了，弃；< −40 会削掉宿主缓坡，弃）
- 实测 **12/12 seed 落地，最大 13 步**。挡路者在三个失败 seed 上是同一个几何原因：
  南边隔一个 region 的第二座高台地带（800 口径下净距恒 **−138**，600 口径是 −76）。

⚠️ **搜索必须排除宿主自己**，否则第一个候选就被自己挡掉。

⚠️ **「避让结构占地」只能防「块压住旧锚点」，防不住「锚点移位」**（实测推翻了我的初版假设）：
大竞技场 / 废弃堡垒的口径是「取距城市最近的合法候选 + span 先严后松」，块内若出现更平坦的沙漠，
就会**抢走**锚点。实测把 base 锚点占地当硬障碍后，选址结果与不加该判据**逐位相同**
（因为 base 锚点本来就在块外）⇒ 该判据对本轮无效，**不要写进实现**。
移位本身是既有选址语义的正常结果，处置见 §8 R7。

### 5.2 三条带与地貌语义

块内按 z 均分三条带（各 800×266.7），从北到南：

| 带 | 上游子样条 | 语义 | 实测（12 seed，800 定稿） |
|---|---|---|---|
| ① 台地 | `club` 的 `plateau` 分支 | 平顶桌山 | **12.1~19.8% 的格恒为同一高度**（平顶），h 最高 34~51 |
| ② 河谷 | `club` 的 `single_valley` 分支 | 下切河谷 | 10.0~17.0% 平顶（谷肩），下切段自动 < `SEA_Y` ⇒ **`fillColumn` 原样填水就成河**（块内水域 7.8~17.3%） |
| ③ 恶地脊 | `club` 的 `ti=5` badlands 分支 | 层脊台阶 | **27.1~45.8% 的格恒为同一高度**（层脊） |

三条带用同一套余弦混合互相接壤（§5.4）。

### 5.3 块内坐标重映射（**载荷性，第一版就是漏了这条导致地形是平的**）

**实测根因**：400 格窗口只覆盖 `ridge` 噪声值域的 **0.69**（中位，800 格 0.99 / 1600 格 1.26），
而 plateau 样条的断点铺在 **±0.5**（全域 p1/p99 = −0.506/+0.556）⇒ 样条只走到中间一支，
地形恒平（第一版实测块内 h ∈ [−15,15] = 与现状同级，台地根本没出现）。

**修法**：块内 x 线性映射到 `[−0.55, +0.55]`，再叠一点真实 ridge 做细节：

```
u     = (x − block.minX) / 800                    // 0..1
coord = −0.55 + u × 1.10 + 0.12 × ridge(x×0.25, block.minZ×0.25)
```

⇒ 每块必然铺满整条样条，**与块在世界里的位置无关**（这也是「不需要水平尺度 k 标定」的原因）。
`0.12` 是细节幅度：实测 0 与 0.12 的平顶占比差 ≤2 个百分点，取 0.12 让边缘不那么机械。

⚠️ **`RIDGE_SPAN = 0.55` 与 `DETAIL = 0.12` 是一组耦合常量**：detail 太大会把 coord 推出
样条端点（端点外是按 derivative 线性外插，不是 clamp），高度会失控。改任一个都要重测值域。

### 5.4 接缝：48 格余弦混合带，**只向块内**（载荷性）

- **块↔外界**：`dIn = min(x−minX, maxX−x, z−minZ, maxZ−z)`。
  **`dIn < 0`（块外）直接返回现状高度**；`dIn ≥ 48` 纯新地形；`0 ≤ dIn < 48` 按
  `w = 0.5 − 0.5·cos(π·dIn/48)` 从现状高度过渡到块高度。**整条混合带都在块内。**
- **带↔带**：同一公式，用「到本带 z 边界的距离」，与相邻带混合（也只在块内）。

⚠️ **不能写成「混合带向内外各伸 24 格」**（初版写法，实测造成真缺陷）：
块的 `minZ` 紧贴宿主地带南缘，向外伸 24 格就**伸进了宿主缓坡**——
实测宿主圆内 **139~594 格高度被改（最大 7 格）**，其中 603 格在平台半径内。
改成只向内后实测 **宿主被改 0 格（12/12 seed）**，且界外零 Perlin 的早退条件更简单（`dIn < 0`）。

实测块内邻格最大高差 **29~32 格**（11/12 seed），最差 **47 格**（seed 3740，它的 h 最高 51）；
现状自然地形本身是 **11 格**。对照：硬切边界会到 **62 格**（`MAX_STEP=1.0` 完全爬不上，等于世界墙）。

**混合带宽扫描**（inward-only，12 seed，宿主均零改动）：

| W | 最大邻格跳 | ≥5 格% 均 | 平顶% 均（台地/河谷/恶地） |
|---|---|---|---|
| **48** | **27** | 0.253 | **16.7 / 12.6 / 35.1** |
| 64 | 26 | 0.245 | 16.0 / 12.3 / 29.7 |
| 80 | 26 | 0.235 | 15.2 / 11.9 / 24.8 |
| 96 | 27 | 0.224 | 14.4 / 11.5 / 20.2 |
| 120 | 26 | 0.210 | 13.0 / 10.9 / 16.0 |

⇒ **加宽混合带并不降低最大跳变**（26~27 恒定，那是地貌内部的陡崖，不是接缝），
却把平顶占比腰斩（恶地脊 35.1% → 16.0%）⇒ **取 W=48**，不取更宽。

⚠️ 上表的 27 与定稿逐 seed 表的 29~32 口径不同：扫描用步长 3 采样，定稿表用步长 2 且逐格算邻差。
引用时必须带采样口径，不可混用。

### 5.5 保留既有 biome 压平（**载荷性**）

新高度算完后仍套 `DESERT ×0.5+2` / `SWAMP ×0.3−2` / `CITY ×0.25+1`。
实测单变量对照（只差这一条，四族口径）：

| | 丢弃压平 | 保留压平 |
|---|---|---|
| 大竞技场 | **1/8 seed** | **8/8** |
| 废弃堡垒 | **3/8** | **8/8** |
| 金字塔 span≤4 可用 region | 1/22 | 5/22 |

### 5.6 水面：只同步 TSL 高度输入

- `ocean-mask.js`（CPU 判据）**一行不改** —— 它调 `generateHeight`，自动跟随。
- `ocean.js` 的 `getTerrainHeight` 需同步：加块矩形早退 + 三条子样条的 TSL 翻译。
  **五点取样、阈值、城市/湖区门控、`Discard` 顺序全部不动。**
- 块矩形通过 uniform 传入（手法照抄既有 `setCityBounds` / `setLakeCircle`：
  默认哨兵 = 空矩形 ⇒ 未接线时门控关闭、不误伤任何点）。
- 成本：块外片元 **0 额外 octave**（矩形早退）；块内 **17~27 octave/片元**。

## 7. 实测证据（本轮探针，可复现）

**手法**：`cp -r src /tmp/mcterr/src`，**只注入 `generateHeightForBiome`**（其余全用仓库原样代码：
`fillColumn` / `carveCaves` / `computeSkylightColumn` / **真实 `buildSectionMesh`** / registry / atlas）。
每轮结束 `diff -rq src /tmp/mcterr/src` 确认水面代码未被改动、`git status` 确认工作树干净。

⚠️ **ESM 只加载一次**：钩子必须在 `import` **之前**装好，之后只换 `globalThis` 上的函数。
**本轮踩了两次同一个坑**：第一版探针在 import 后改文件 ⇒ 所有候选都跑原公式，得出「8/8 全活」的假对照；
改 800 时又在补充探针里犯一次，得出「锚点位移 0」与主探针「6 个 moved」**相互矛盾**的结论。
定位手法：把两个探针的 `makeFn` 逐字比对（确认逻辑相同）→ 比对 import 与注入的**位置先后** ⇒ 找到真因。
**每个探针必须带自检**：装块后块中心高度必须真的变了，否则 `throw`。

⚠️ **锚点类对照必须清全部四个缓存**：`clearArenaCache` 也得调 —— 围场锚点是
大竞技场/废弃堡垒选址的 blocker 输入（`fixedBlockerAt` 消费它），漏清会串味。

## 9. 验证计划（按 `docs/testing-policy.md` 分级）

### Tier 1（必须 TDD，RED → GREEN → REFACTOR）
`src/tests/test-mesa-block.js`：
1. **spline 端点语义**：`spline(idxPts, 0) === 3`（clamp 版得 −25）；端点外按 derivative 线性外插。
2. **Perlin 确定性**：同 `(x,z,seed)` 逐位相同；值域 ⊂ [−1,1]；无 NaN。
3. **块位置确定性**：同 seed 逐位相同；12 seed 全部落地；与宿主净距 ∈ [−40,120]。
4. **避让**：与其它高台地带 / 城市 / 四个结构占地净距 **≥32**（逐 seed 断言，且 `checked > 0` 防恒真）。
5. **界外逐位不变**：块矩形外的采样点，高度与「不装块」逐位相同（**本轮核心不变式**）。
6. **宿主地带圆内零改动**：宿主圆（半径 138）内逐格高度与 base 相同。⚠️ **必须单独写**：R8 的缺陷落在块矩形**外**，只钉上一条会漏掉它。
6. **既有锚点不失败**：四个结构在 12 seed 上均非 null（**移位可接受，失败不可接受** —— 分开断言）。
7. **三条带形态**：各带的「同一高度占比」≥ 下界（钉住「地形不是平的」，第一版缺陷正是这条缺失）；
   块内高度**同时钉上下界**（只钉「变高」抓不到「炸出世界」）。
8. **coord 值域** ⊂ 样条断点范围（防 R4）。
9. **接缝**：块内邻格最大高差 ≤ 上界（取实测 47 + 余量），且 **> `MAX_STEP`** 的占比 ≤ 上界。
10. **移位锚点仍合法**：移位后的锚点 `candidateValid` 仍通过（防「勉强生成」，R7）。
