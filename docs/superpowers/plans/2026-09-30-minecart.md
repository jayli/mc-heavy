# 矿车 Epic 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 把 `mine_cart` 从「背包里一个什么都不做的平面图标」做成完整可玩实体：放置渲染、沿铁轨移动、转弯、车-车碰撞与连挂列车、玩家拾取/激活/乘坐、爆炸摧毁，行为语义 100% 对齐 mc-lite。

**Architecture:** 矿车是 **M5 持久实体**（state 权威在 `EntityManager`，白拿 entities store 写盘 / column 两阶段卸载 / `_discardEdits` 清理）。移动/碰撞/连挂抽成 `src/entities/minecarts/` 的同构纯函数（无 three、无 DOM），由 `minecartDefinition.update` 经 `EntityManager.update` 驱动；跨车写入排队、循环后统一生效。渲染是 2 个 InstancedMesh（车斗 + 4 轮），照 M6/M8 手法（差集驱动 slot、零实例 `visible=false`）。命中走 `EntityManager.raycast()`（红线 6），不碰 three Raycaster。

**Tech Stack:** 纯 JavaScript ES2022 + JSDoc（禁 TypeScript、无 bundler）、three.js r185.1（本地 `vendor/three/`，WebGPU 唯一后端）、浏览器内单测（`src/tests/`）+ Playwright E2E（`tests/`）。

**Spec:** `docs/superpowers/specs/2026-09-30-minecart-design.md`（本计划逐条实现它；执行时两份都要读）

## Global Constraints

- **纯 JavaScript（ES2022+ ESM）+ JSDoc，禁止 TypeScript，无编译/转译、无 bundler。**
- **`src/entities/**` 是同构层：不得 import three、不得引用 DOM、不得新建 Worker**（`npm run check:arch` 静态门守；`new Worker` 唯一合法落点是 `src/core/worker-pool.js`）。
- **红线 1 数据只有一份权威**：矿车 state 权威 = `EntityManager`；`MinecartService` 的位置索引是派生缓存（可全量重建）。`TRACK_BLOCK_TYPES` / 速度 / 上限 / 几何尺寸等常量单一权威在 `minecart-config.js`，消费方不得写字面量。
- **红线 6 实体命中唯一入口 = `EntityManager.raycast()`**：拾取/激活不得对 InstancedMesh 做 `THREE.Raycaster.intersectObjects`。
- **`definition.update` 必须返回全新 state + 全新数组**（M6 活跃约束）：原地改写会让 `EntityManager.update` 的跨 column 索引迁移判据恒等 → 卸载漏回收。浅拷贝不够（position 数组引用相同仍被污染）。
- **时间基准统一 `performance.now()`，禁止 `Date.now()`**（两者相差约 17 亿毫秒）。
- **速度单位已核对：`MINECART.speed = 2.0` 格/秒，不做 ×60 换算**（mc-lite 该处乘 deltaTime，与 `ZOMBIE.speed` 的格/帧相反）。
- **实例原点换算 +0.5**：mc-heavy 实体 position 是占据格坐标（块底角原点），渲染位置 = `position + (0.5, 0, 0.5)`。
- **常驻 InstancedMesh 无活跃实例时必须 `visible = false`**（否则恒增 draw call）。
- **从实例矩阵反解 yaw 用 `atan2(elements[8], elements[0])`**，不得用 `Euler.setFromQuaternion`（会折叠到 ±π/2）。
- **坐标取模一律 `((n % 16) + 16) % 16` 或直接枚举足迹**（`n % 16` 在负坐标下是取余，判据会恒真）。
- **写断言前先在真实数据上跑一次、打印实际值**（testing-policy §2.6 ⑤）；负向验证注入后断言须真 FAIL（§2.7）。
- **门禁分层**：改纯函数/协议/数据模型（Tier 1）跑 `npm run check` + `npm test`；改热路径再加 `npm run bench -- --check`。改 `src/**/*.js` 后跑 `npm run lint`。
- **每个 Task 结束必须 commit**（Conventional Commits：`feat:` / `test:` / `chore:` / `docs:`）。
- **计时型断言 flaky 时先做交替对照**（MOD/BASE 交错各 3 轮比中位），不看单次数值；不带 `--check` 跑 bench 会自动重写冻结基线，诊断后须 `git checkout docs/m3-baseline.md docs/m3-baseline.json` 恢复。
- **dev server 必须「启动 + 使用 + 关闭」在同一条命令内**（会话间后台进程会被杀）；8081 已有本项目 server 在跑则直接复用。

```js
import { BLOCKS } from '../voxel/blocks-data.js';
import { ChunkColumn } from '../voxel/chunk-column.js';
import { WorldData } from '../voxel/world-data.js';
import { EntityManager } from '../entities/entity-manager.js';

function makeRegistry() {
  const reg = createRegistry();
  for (const def of BLOCKS) reg.register(def.name, def);

  for (let cx = -1; cx <= 2; cx++) {
    for (let cz = -1; cz <= 2; cz++) {

      col.state = 'ready';
      world.add(col);
    }
  }
  return { world, registry };

  assertEqual(directionOf(0, MOVEMENT.FORWARD).x, 1, 'EAST 前进 → +x');
  assertEqual(directionOf(0, MOVEMENT.FORWARD).z, 0);
  assertEqual(directionOf(1, MOVEMENT.FORWARD).z, 1, 'SOUTH 前进 → +z');
  assertEqual(directionOf(2, MOVEMENT.FORWARD).x, -1, 'WEST 前进 → -x');
  assertEqual(directionOf(3, MOVEMENT.FORWARD).z, -1, 'NORTH 前进 → -z');

test('leftOf/rightOf: 与前进方向正交，且公式对齐 mc-lite', () => {
  for (let o = 0; o < 4; o++) {
    const f = directionOf(o, MOVEMENT.FORWARD);
    const l = leftOf(o);
    const r = rightOf(o);
    assertEqual(f.x * l.x + f.z * l.z, 0, `朝向 ${o} 的左向须与前进正交`);
    assertEqual(f.x * r.x + f.z * r.z, 0, `朝向 ${o} 的右向须与前进正交`);
    // mc-lite 公式：left = (-fz, fx)，right = (fz, -fx)
    assertEqual(l.x, -f.z, `朝向 ${o} 左向 x = -forward.z`);
    assertEqual(l.z, f.x, `朝向 ${o} 左向 z = forward.x`);
    assertEqual(r.x, f.z, `朝向 ${o} 右向 x = forward.z`);
    assertEqual(r.z, -f.x, `朝向 ${o} 右向 z = -forward.x`);
  }
});
```

```js
// src/entities/minecarts/minecart-config.js — 矿车冻结玩法数据（设计文档 §2/§3/§5）
// 同构层：**无 DOM、无 three**（`npm run check:arch` 静态门守）。
// 本文件是矿车玩法数值与几何尺寸的**唯一权威** —— system / service / renderer / 测试
// 都从这里派生，不得各自写字面量（红线 1）。数值逐项实测自 mc-lite
// `constants/GameConfig.js` + `actors/minecart/Minecart.js` + `MinecartInstancedRenderer.js`
// （读源，非推断）。

/**
 * ⚠️ **单位换算已核对：不做 ×60**。mc-lite `MinecartMovementSystem.update` 的位移是
 * `direction * MINECART_SPEED * deltaTime` → 已是**格/秒**。与 `ZOMBIE.speed` 那种
 * 「格/帧须 ×60」的情况相反（`Zombie.js` 的 `predictNextPosition` 不乘 dt）。
 * 「照搬前逐项核对是否乘 dt」是 CLAUDE.md 的活跃约束（M8 已沉淀）。
 */
export const MINECART = Object.freeze({
  /** 移动速度 2.0 格/秒（mc-lite `GameConfig.MINECART_SPEED`） */
  speed: 2.0,
  /** 全局上限 50 辆（mc-lite `MAX_MINECARTS`）。判定来源 = entities store，见 service */
  maxMinecarts: 50,
  /** 连挂列车上限 10 辆（mc-lite `MAX_LINKED_MINECARTS`） */
  maxLinked: 10,
  /** 碰撞盒 1.0×0.9×1.0（mc-lite `MINECART_CONFIG.BOUNDING_BOX`） */
  width: 1.0,
  height: 0.9,
  /** 车顶高度 = 玩家乘坐时脚底 y（mc-lite `minecartTopY = position.y + 0.9`） */
  rideHeight: 0.9,
  /** 下车后禁止自动重绑的冷却秒数（mc-lite `minecartRemountCooldown = 0.25`） */
  remountCooldown: 0.25,
  /** 水平偏离超过此值自动下车（mc-lite `deviationX > 0.6`） */
  dismountDeviation: 0.6,
  /** 绑定判据：|playerY − 车顶| < 此值（mc-lite `isOnMinecart` 的 0.3） */
  rideBindTolerance: 0.3,
  /**
   * 交互射程 15 格（mc-lite `PlayerInteraction.interact` 的 `hits[0].distance < 15`）。
   * ⚠️ 与体素 DDA 的 `REACH = 40` **不是一个口径** —— 实体交互更近，超出 15 格点不到车。
   * 拾取与激活共用本常量，不得各写字面量（红线 1）。
   */
  interactRange: 15,
  /** 车斗尺寸 0.9×0.8×0.9（mc-lite `MINECART_SIZES.body`） */
  bodyWidth: 0.9,
  bodyHeight: 0.8,
  bodyDepth: 0.9,
  /** 车斗底部内缩比例（mc-lite `shrinkRatio = 0.8` → 倒梯形） */
  bodyShrinkRatio: 0.8,
  /** 车轮半径 / 高度（mc-lite `wheelRadius` / `wheelHeight`） */
  wheelRadius: 0.2,
  wheelHeight: 0.1,
  /** 轴距（前后轮间距）/ 轮距（左右轮间距），均 0.6 */
  wheelbase: 0.6,
  trackWidth: 0.6,
  /** 车斗 / 车轮颜色（mc-lite `MINECART_COLORS`） */
  bodyColor: 0xb8bec6,
  wheelColor: 0x2f3238,
  /** 车斗材质金属度 / 粗糙度（mc-lite `metalness: 0.22, roughness: 0.72`）。
   *  ⚠️ **本仓库无消费点**（死字段）：mc-heavy 全场景 unlit，材质用 MeshBasicMaterial
   *  （`zombie-renderer.js:32` 同口径）→ 这两个 PBR 参数不参与渲染。保留仅作 mc-lite 出处记录。 */
  bodyMetalness: 0.22,
  bodyRoughness: 0.72,
  /** 车斗纹理边长（mc-lite `createMinecartBodyTexture` 的 size = 128） */
  textureSize: 128,
  /**
   * 爆炸摧毁的度量偏移与半径（mc-lite `PlayerInteraction.js` 的爆炸段）：
   * 爆炸中心 = 方块格 + 0.5（块中心），车中心 = 车 position + (0.5, 0.3, 0.5)，半径 4。

});

/**
 * 铁轨方块类型（mc-lite `GameConfig.TRACK_BLOCK_TYPES`）。
 * **单一权威**：移动系统的 `hasTrackAt` 与放置预检都读它，不得各写字面量（红线 1）。
 */
export const TRACK_BLOCK_TYPES = Object.freeze(['sand_train_track', 'sand_train_track_corner']);

/** 背包物品名（mc-lite 同名；已在 `buildItemNames()` 集合内，走平面图标路径） */
export const MINECART_ITEM = 'mine_cart';

/** EntityManager 的实体 type 名（snapshot / raycast predicate / 渲染过滤都用它） */
export const MINECART_TYPE = 'minecart';

/**
 * 移动状态枚举。⚠️ 用小写串（mc-lite 用 `'MOVING_FORWARD'` 大写，本仓库对齐 M6 的
 * `'idle'`/`'chasing'` 风格）—— 值会进 snapshot，改口径须同时考虑旧存档。
 */
export const MOVEMENT = Object.freeze({
  IDLE: 'idle',
  FORWARD: 'forward',
  BACKWARD: 'backward',
});

/**
 * 矿车 AABB（相对 state.position 的局部偏移）。
 * ⚠️ **position 是占据格坐标（块底角原点），不是块中心** —— 故盒是 [0, width]
 * 而不是 [±width/2]（后者是「脚底中心」语义的盒，如 PROBE_AABB —— 两种 position
 * 语义不得混用）。mc-lite `Minecart.js:70-80` 的 `getBoundingBox()` 在同样的格角
 * position 上给出 `min = pos + (1-width)/2 = pos`、`max = pos + 1`（width=1）→
 * 盒 `[pos, pos+1]`，与本常量逐位等价（渲染层另有 +0.5 的块中心换算，不影响命中盒）。
 */
export const MINECART_AABB = Object.freeze({
  min: Object.freeze([0, 0, 0]),
  max: Object.freeze([MINECART.width, MINECART.height, MINECART.width]),
});

/**
 * 朝向 → 水平方向向量（mc-lite `DIRECTION_VECTORS`：0=EAST, 1=SOUTH, 2=WEST, 3=NORTH）。
 * 与 `src/player/orientation.js` 的 `BlockOrientation` 同枚举（铁轨 meta 朝向直接可用）。
 */
const DIRECTION_VECTORS = Object.freeze([
  Object.freeze({ x: 1, z: 0 }),    // EAST
  Object.freeze({ x: 0, z: 1 }),    // SOUTH
  Object.freeze({ x: -1, z: 0 }),   // WEST
  Object.freeze({ x: 0, z: -1 }),   // NORTH
]);

/**
 * 取运动方向（后退时反向）。mc-lite `getDirectionVector` 同语义：只判 BACKWARD，
 * 其余（含 IDLE）返回基础方向 —— IDLE 的车根本走不到位移分支。
 * 越界朝向回落 EAST（mc-lite `|| DIRECTION_VECTORS[0]`）。
 * @param {number} orientation 0-3
 * @param {string} movementState MOVEMENT.*
 * @returns {{x: number, z: number}}
 */
export function directionOf(orientation, movementState) {
  const base = DIRECTION_VECTORS[orientation] ?? DIRECTION_VECTORS[0];
  if (movementState === MOVEMENT.BACKWARD) return { x: -base.x, z: -base.z };
  return { x: base.x, z: base.z };
}

/**
 * 左向（mc-lite `getLeftDirection` 的公式：`(x,z) → (-z, x)`）。
 * ⚠️ mc-lite 的注释写「顺时针旋转90度」但公式给出的是另一侧 —— **照公式搬，不照注释搬**
 * （「对齐上游须实测其运行时行为，不能读定义推断」，CLAUDE.md 活跃约束）。
 * @param {number} orientation 0-3 @returns {{x: number, z: number}}
 */
export function leftOf(orientation) {
  const f = DIRECTION_VECTORS[orientation] ?? DIRECTION_VECTORS[0];
  return { x: -f.z, z: f.x };
}

/** 右向（mc-lite `getRightDirection` 的公式：`(x,z) → (z, -x)`）。 */
export function rightOf(orientation) {
  const f = DIRECTION_VECTORS[orientation] ?? DIRECTION_VECTORS[0];
  return { x: f.z, z: -f.x };
}

/**
 * 朝向 → Y 轴旋转弧度（mc-lite `OrientationUtils.getRotationAngle`：`orientation * π/2`）。
 * **渲染层与逻辑层共用本函数** —— 各写一份会漂移出「车朝东走但模型朝南」（红线 1）。
 * @param {number} orientation 0-3 @returns {number}
 */
export function rotationAngleOf(orientation) {
  return (orientation || 0) * (Math.PI / 2);
}

/** registry → 铁轨 id 集合的缓存（移动热路径每帧多次查询，不得每次 map 一遍） */
const _trackIdCache = new WeakMap();

/**
 * 方块 id 是否铁轨。
 * @param {number} id
 * @param {ReturnType<import('../../voxel/block-registry.js').createRegistry>} registry
 * @returns {boolean}
 */
export function isTrackBlock(id, registry) {
  if (!registry) return false;
  let set = _trackIdCache.get(registry);
  if (!set) {
    set = new Set();
    for (const name of TRACK_BLOCK_TYPES) {
      const trackId = registry.idOf(name);
      if (trackId !== undefined) set.add(trackId);
    }
    _trackIdCache.set(registry, set);
  }
  return set.has(id);
}

/**
 * 指定格是否铁轨。⚠️ **「铁轨在车下方一格」（`trackY = carY - 1`）是调用方的责任**，
 * 本函数只判「这一格是不是铁轨」—— mc-lite `hasTrackAt` 同口径。
 * `registry` 缺省时从 `world.registry` 取（`WorldData` 构造期持有）。
 */
export function hasTrackAt(world, registry, x, y, z) {
  if (!world) return false;
  return isTrackBlock(world.getBlockId(x, y, z), registry ?? world.registry);
}

/** 指定格是否实心（`registry.solidTable`，对应 mc-lite `getBlockProperties().isSolid`）。 */
export function hasSolidAt(world, registry, x, y, z) {
  if (!world) return false;
  const id = world.getBlockId(x, y, z);
  if (id === 0) return false;
  const reg = registry ?? world.registry;
  return reg ? reg.solidTable[id] === 1 : false;
}
```

```js
// src/entities/minecarts/minecart-system.js — 矿车移动/碰撞/连挂同构纯函数 + 玩法入口
// 同构层：**无 DOM、无 three、不新增 Worker**（`npm run check:arch` 静态门守）。
//
// 行为语义逐条移植 mc-lite `MinecartMovementSystem` / `MinecartCollisionSystem` /
// `MinecartLinkDetector`（设计文档 §3）；**架构不搬**（红线 1/6，设计文档 §6 偏离表）。
//
// ⚠️ 与 mc-lite 的结构性差异：mc-lite 是单管理器循环直接改对象；本仓库的
// `EntityManager.update` 逐实体调 `definition.update` 且要求**返回全新 state**
// （M6 活跃约束）。故对他车的写入一律进 `deferred` 队列，由 service 在循环后统一生效。
import {
  MINECART, MOVEMENT, MINECART_AABB, directionOf, leftOf, rightOf,
  isTrackBlock, hasTrackAt, hasSolidAt,
} from './minecart-config.js';
import { normalizePosition, raycastAabbSlab } from '../entity-types.js';

/** 位置索引键（floor 后拼串，mc-lite `getPositionKey` 同口径）。 */
export function cellKey(x, y, z) {
  return `${Math.floor(x)},${Math.floor(y)},${Math.floor(z)}`;
}

/**
 * 车所在格的四邻可用轨道方向（mc-lite `getAvailableTrackDirections`）。
 * ⚠️ **铁轨在车下方一格**（`trackY = carY - 1`）。
 * @returns {number[]} 可用朝向（0-3），可能为空
 */
export function availableTrackDirections(world, registry, carX, carY, carZ) {
  const trackY = carY - 1;
  const out = [];
  for (let orientation = 0; orientation < 4; orientation++) {
    const d = directionOf(orientation, MOVEMENT.FORWARD);
    if (hasTrackAt(world, registry, carX + d.x, trackY, carZ + d.z)) out.push(orientation);
  }
  return out;
}

/**
 * 按可用轨道调整朝向（mc-lite `alignMinecartToTrack`）。
 * @returns {number|null} 可走 → 朝向；无相邻轨道 → null
 */
export function alignToTrack(world, registry, orientation, carX, carY, carZ) {
  const available = availableTrackDirections(world, registry, carX, carY, carZ);
  if (available.length === 0) return null;
  if (available.includes(orientation)) return orientation;
  // 选与当前朝向差最小的方向（避免 180° 大转弯，mc-lite 同逻辑）
  let best = available[0];
  let minDiff = 4;
  for (const dir of available) {
    const diff = Math.min(Math.abs(dir - orientation), 4 - Math.abs(dir - orientation));
    if (diff < minDiff) { minDiff = diff; best = dir; }
  }
  return best;
}

/**
 * 转弯检测（mc-lite `checkTurn`）。**左优先**：只有左侧不可走才试右侧。
 * ⚠️ 后退时左右互换（mc-lite 同口径）。
 * @param {{x:number,y:number,z:number}} trackPos 车所在格（y 是车的 y，不是轨道 y）
 * @returns {{turn: 'left'|'right'|null, newOrientation: number|null}}
 */
export function checkTurn(world, registry, orientation, movementState, trackPos) {
  const backward = movementState === MOVEMENT.BACKWARD;
  const left = backward ? rightOf(orientation) : leftOf(orientation);
  const right = backward ? leftOf(orientation) : rightOf(orientation);
  const trackY = trackPos.y - 1;
  if (hasTrackAt(world, registry, trackPos.x + left.x, trackY, trackPos.z + left.z)) {
    return { turn: 'left', newOrientation: (orientation + 1) % 4 };
  }
  if (hasTrackAt(world, registry, trackPos.x + right.x, trackY, trackPos.z + right.z)) {
    return { turn: 'right', newOrientation: (orientation + 3) % 4 };
  }
  return { turn: null, newOrientation: null };
}

/**
 * 相向判定（mc-lite `isHeadOn`）：A 的前方格是 B 所在格，且 B 的前方格是 A 所在格。
 * 任一方 idle → false（mc-lite 首行门控）。
 */
export function isHeadOn(a, b) {
  if (a.movementState === MOVEMENT.IDLE || b.movementState === MOVEMENT.IDLE) return false;
  const da = directionOf(a.orientation, a.movementState);
  const db = directionOf(b.orientation, b.movementState);
  const ax = Math.floor(a.position[0]), az = Math.floor(a.position[2]);
  const bx = Math.floor(b.position[0]), bz = Math.floor(b.position[2]);
  return (ax + da.x === bx && az + da.z === bz) && (bx + db.x === ax && bz + db.z === az);
}

/**
 * 静止车能否被激活（mc-lite `canActivateStaticMinecart`）：
 * ① 继承运动车方向后，前方格不得有实心阻挡；② 前方有轨道，**或**左右任一侧可转向。
 */
export function canActivateStatic(world, registry, moving, staticCar) {
  const d = directionOf(moving.orientation, moving.movementState);
  // mc-lite 用 round 取轨道格（避免 floor 的 0.5 格偏差）
  const trackX = Math.round(staticCar.position[0]);
  const trackY = Math.floor(staticCar.position[1]);
  const trackZ = Math.round(staticCar.position[2]);
  const railY = trackY - 1;
  if (hasSolidAt(world, registry, trackX + d.x, trackY, trackZ + d.z)) return false;
  if (hasTrackAt(world, registry, trackX + d.x, railY, trackZ + d.z)) return true;
  const backward = moving.movementState === MOVEMENT.BACKWARD;
  const left = backward ? rightOf(moving.orientation) : leftOf(moving.orientation);
  const right = backward ? leftOf(moving.orientation) : rightOf(moving.orientation);
  return hasTrackAt(world, registry, trackX + left.x, railY, trackZ + left.z)
    || hasTrackAt(world, registry, trackX + right.x, railY, trackZ + right.z);
}

/**
 * 连挂递归（mc-lite `MinecartLinkDetector.findAllLinked`）：沿朝向找**相邻格、同朝向**的车。
 * 用显式栈而非递归（mc-lite 是递归 + visited，行为等价；栈版无调用深度风险）。
 * @param {Map<string, object>} byId id → state
 * @param {string} startId
 * @returns {string[]} 含自身，长度 ≤ `MINECART.maxLinked`
 */
export function findLinked(byId, startId) {
  const visited = new Set();
  const stack = [startId];
  while (stack.length > 0 && visited.size < MINECART.maxLinked) {
    const id = stack.pop();
    if (visited.has(id)) continue;
    const c = byId.get(id);
    if (!c) continue;
    visited.add(id);
    const d = directionOf(c.orientation, MOVEMENT.FORWARD);
    const cx = Math.floor(c.position[0]);
    const cy = Math.floor(c.position[1]);
    const cz = Math.floor(c.position[2]);
    for (const [dx, dz] of [[d.x, d.z], [-d.x, -d.z]]) {
      const key = cellKey(cx + dx, cy, cz + dz);
      for (const [otherId, other] of byId) {
        if (otherId === id || visited.has(otherId)) continue;
        if (cellKey(other.position[0], other.position[1], other.position[2]) !== key) continue;
        if (other.orientation !== c.orientation) continue;   // 同朝向才连挂
        stack.push(otherId);
      }
    }
  }
  return [...visited];
}

/** 深拷贝 state（**position/lastTrack 数组必须是新的** —— M6 活跃约束）。 */
function cloneState(s) {
  return {
    position: [s.position[0], s.position[1], s.position[2]],
    orientation: s.orientation,
    movementState: s.movementState,
    lastTrack: s.lastTrack ? [s.lastTrack[0], s.lastTrack[1], s.lastTrack[2]] : null,
    pendingTargetCell: s.pendingTargetCell ? { ...s.pendingTargetCell } : null,
    linked: Array.isArray(s.linked) ? [...s.linked] : [],
  };
}

/**
 * 玩家阻挡判定（mc-lite `checkPlayerCollision` 逐行语义）。
 * @returns {'none'|'stop'|number} `number` = 应把玩家脚底抬到的 y
 */
function resolvePlayerBlocking(world, registry, state, player, frontX, frontZ) {
  const minecartTopY = state.position[1] + MINECART.rideHeight;
  const [px, py, pz] = player.position;
  const halfW = 0.3;   // 玩家 AABB 半宽（与 player/physics.js 的 PLAYER_WIDTH/2 同值）
  const overlapsX = px - halfW < frontX + 1 && px + halfW > frontX;
  const overlapsZ = pz - halfW < frontZ + 1 && pz + halfW > frontZ;
  if (!overlapsX || !overlapsZ) return 'none';
  if (py >= minecartTopY - 0.1) return 'none';   // 玩家已在车顶之上
  const playerFloorX = Math.floor(px);
  const playerFloorZ = Math.floor(pz);
  for (let dy = 0; dy <= 2; dy++) {              // mc-lite 检查 dy 0..2
    if (hasSolidAt(world, registry, playerFloorX, Math.floor(minecartTopY + dy), playerFloorZ)) {
      return 'stop';
    }
  }
  return minecartTopY;
}

/**
 * 单车一帧的推进计划（mc-lite `MinecartMovementSystem.update` 的纯函数化）。
 *
 * **为什么返回计划而不是直接改 state**：`EntityManager.update` 逐实体调
 * `definition.update`，跨车写入必须排队（见文件头 ⚠️）。本函数只读 world / service，
 * 输出 `{state, deferred, liftPlayer}`。
 *
 * 判定顺序照 mc-lite 逐条搬（**顺序不得调整**）：
 * ① idle 早退 → ② 跨中心时检查前方轨道 → ③ 转弯 → ④ 声明冲突 → ⑤ 前方车
 * → ⑥ 前方玩家 → ⑦ 前方实心 → ⑧ 声明目标格 → ⑨ 帧预占位 → ⑩ 位移。
 */
export function planMinecartStep({ state, dt, world, registry, service, selfId, player = null }) {
  const deferred = [];
  // ① idle 不动。仍返回全新对象（M6 约束）
  if (state.movementState === MOVEMENT.IDLE) {
    return {
      state: cloneState({ ...state, pendingTargetCell: null }),
      deferred, liftPlayer: null,
    };
  }

  const dir = directionOf(state.orientation, state.movementState);
  // 轨道判定用「最近轨道中心」（round）；位置索引用 floor（mc-lite 同口径）
  const currentTrackX = Math.round(state.position[0]);
  const currentTrackZ = Math.round(state.position[2]);
  const currentX = Math.floor(state.position[0]);
  const currentY = Math.floor(state.position[1]);
  const currentZ = Math.floor(state.position[2]);
  const trackY = currentY - 1;

  // 到达已声明目标格 → 清声明（避免长期占位）
  let pendingTargetCell = state.pendingTargetCell;
  if (pendingTargetCell && pendingTargetCell.x === currentX
      && pendingTargetCell.y === currentY && pendingTargetCell.z === currentZ) {
    pendingTargetCell = null;
  }

  const localX = state.position[0] - currentTrackX;
  const localZ = state.position[2] - currentTrackZ;
  const stepLen = MINECART.speed * dt;
  const newX = state.position[0] + dir.x * stepLen;
  const newZ = state.position[2] + dir.z * stepLen;
  const nextCellX = Math.floor(newX);
  const nextCellZ = Math.floor(newZ);
  const newLocalX = newX - currentTrackX;
  const newLocalZ = newZ - currentTrackZ;

  // 是否跨越轨道中心（只在移动方向上跨才算）
  const crossedCenterX = (dir.x > 0 && localX <= 0 && newLocalX > 0)
    || (dir.x < 0 && localX >= 0 && newLocalX < 0);
  const crossedCenterZ = (dir.z > 0 && localZ <= 0 && newLocalZ > 0)
    || (dir.z < 0 && localZ >= 0 && newLocalZ < 0);
  const shouldCheck = (dir.x !== 0 && crossedCenterX) || (dir.z !== 0 && crossedCenterZ);

  /** 停车并吸附到指定轨道格（mc-lite `stopMinecartAtCell`） */
  const stopped = (x, z) => cloneState({
    ...state,
    position: [x, state.position[1], z],
    movementState: MOVEMENT.IDLE,
    lastTrack: [x, currentY, z],
    pendingTargetCell: null,
  });
  /** 本帧不推进（等待/转弯/激活）：位置不变，只更新声明 */
  const held = (patch = {}) => cloneState({ ...state, ...patch, pendingTargetCell });

  if (shouldCheck) {
    const frontX = currentTrackX + dir.x;
    const frontZ = currentTrackZ + dir.z;

    // ②③ 前方无轨道 → 转弯或停
    if (!hasTrackAt(world, registry, frontX, trackY, frontZ)) {
      const turn = checkTurn(world, registry, state.orientation, state.movementState,
        { x: currentTrackX, y: currentY, z: currentTrackZ });
      if (turn.turn) {
        // 可转弯：更新朝向，**本帧不推进**（mc-lite 同口径）
        return {
          state: cloneState({ ...state, orientation: turn.newOrientation, pendingTargetCell: null }),
          deferred, liftPlayer: null,
        };
      }
      return {
        state: stopped(currentTrackX, currentTrackZ), deferred, liftPlayer: null,
      };
    }

    // ④ 跨帧目标格声明冲突
    if (service) {
      for (const other of service.cars()) {
        if (!other || other.id === selfId) continue;
        if (other.state.movementState === MOVEMENT.IDLE) continue;
        const claim = other.state.pendingTargetCell;
        if (!claim) continue;
        if (claim.x === frontX && claim.y === currentY && claim.z === frontZ) {
          return { state: held(), deferred, liftPlayer: null };
        }
      }
    }

    // ⑤ 前方有车
    const otherCar = service ? service.carAt(frontX, currentY, frontZ) : null;
    if (otherCar) {
      const otherState = otherCar.state;
      // 相向 → 两车都停（对方经 deferred）
      if (isHeadOn(state, otherState)) {
        const ox = Math.round(otherState.position[0]);
        const oz = Math.round(otherState.position[2]);
        deferred.push({
          id: otherCar.id,
          patch: {
            movementState: MOVEMENT.IDLE,
            position: [ox, otherState.position[1], oz],
            lastTrack: [ox, Math.floor(otherState.position[1]), oz],
          },
        });
        return { state: stopped(currentTrackX, currentTrackZ), deferred, liftPlayer: null };
      }
      // 运动撞静止 → 尝试激活
      if (otherState.movementState === MOVEMENT.IDLE
          && canActivateStatic(world, registry, state, otherState)) {
        deferred.push({
          id: otherCar.id,
          patch: {
            orientation: state.orientation,
            movementState: state.movementState,
            lastTrack: otherState.lastTrack ?? [Math.floor(otherState.position[0]),
              Math.floor(otherState.position[1]), Math.floor(otherState.position[2])],
          },
        });
        // 本帧不推进自己（避免与刚激活的车重叠入格）
        return { state: held(), deferred, liftPlayer: null };
      }
      // 前车仍在运动（非相向）→ 等待
      if (otherState.movementState !== MOVEMENT.IDLE) {
        return { state: held(), deferred, liftPlayer: null };
      }
      // 其余（激活失败）→ 自己停
      return { state: stopped(currentTrackX, currentTrackZ), deferred, liftPlayer: null };
    }

    // ⑥ 前方玩家
    let liftPlayer = null;
    if (player) {
      const playerResult = resolvePlayerBlocking(world, registry, state, player, frontX, frontZ);
      if (playerResult === 'stop') {
        return { state: stopped(currentTrackX, currentTrackZ), deferred, liftPlayer: null };
      }
      if (typeof playerResult === 'number') liftPlayer = playerResult;
    }

    // ⑦ 前方实心（即使有轨道也不能穿）
    if (hasSolidAt(world, registry, frontX, currentY, frontZ)) {
      return { state: stopped(currentTrackX, currentTrackZ), deferred, liftPlayer };
    }

    // ⑧ 声明下一目标格
    pendingTargetCell = { x: frontX, y: currentY, z: frontZ };

    // ⑨ 同帧预占位
    if (service && (nextCellX !== currentX || nextCellZ !== currentZ)) {
      const reservationKey = cellKey(nextCellX, currentY, nextCellZ);
      const holder = service.reservations.get(reservationKey);
      if (holder && holder !== selfId) {
        return { state: held(), deferred, liftPlayer };
      }
      service.reservations.set(reservationKey, selfId);
    }

    // ⑩ 位移（进新格时更新 lastTrack）
    const enteredNewCell = Math.floor(newX) !== currentX || Math.floor(newZ) !== currentZ;
    return {
      state: cloneState({
        ...state,
        position: [newX, state.position[1], newZ],
        lastTrack: enteredNewCell ? [currentX, currentY, currentZ] : state.lastTrack,
        pendingTargetCell,
      }),
      deferred,
      liftPlayer,
    };
  }

  // 未跨中心：直接位移（⑨ 预占位同样适用）
  let liftPlayer = null;
  if (service && (nextCellX !== currentX || nextCellZ !== currentZ)) {
    const reservationKey = cellKey(nextCellX, currentY, nextCellZ);
    const holder = service.reservations.get(reservationKey);
    if (holder && holder !== selfId) {
      return { state: held(), deferred, liftPlayer: null };
    }
    service.reservations.set(reservationKey, selfId);
  }
  const enteredNewCell = Math.floor(newX) !== currentX || Math.floor(newZ) !== currentZ;
  return {
    state: cloneState({
      ...state,
      position: [newX, state.position[1], newZ],
      lastTrack: enteredNewCell ? [currentX, currentY, currentZ] : state.lastTrack,
      pendingTargetCell,
    }),
    deferred,
    liftPlayer,
  };
}
```

```js
/**
 * 新建一份合法 state。**每次都返回全新对象 + 全新数组**（M6 活跃约束）。
 * 瞬态字段（pendingTargetCell / linked）保留 —— `activate`/`applyDeferred` 都经本函数重建，
 * 不保留会让每次重建都清掉目标格声明（同丧尸 `_physAccum` 的理由）。
 */
function createState({ position, orientation, movementState, lastTrack, pendingTargetCell, linked }) {
  const pos = normalizePosition(position);
  if (!pos) return null;
  const orient = Number.isInteger(orientation) && orientation >= 0 && orientation <= 3
    ? orientation : 0;
  const movement = movementState === MOVEMENT.FORWARD || movementState === MOVEMENT.BACKWARD
    ? movementState : MOVEMENT.IDLE;
  const track = Array.isArray(lastTrack) && lastTrack.length === 3 && lastTrack.every(Number.isFinite)
    ? [lastTrack[0], lastTrack[1], lastTrack[2]] : null;
  return {
    position: pos,
    orientation: orient,
    movementState: movement,
    lastTrack: track,
    pendingTargetCell: pendingTargetCell && Number.isFinite(pendingTargetCell.x)
      ? { x: pendingTargetCell.x, y: pendingTargetCell.y, z: pendingTargetCell.z } : null,
    linked: Array.isArray(linked) ? [...linked] : [],
  };
}

/**
 * 每帧推进（由 `EntityManager.update` 驱动）。
 * ⚠️ **跨车写入不在此生效** —— 进 service 的待生效队列，由 game.js 在
 * `entities.update(...)` 之后紧邻一行调 `applyDeferred()`。放进本函数会在遍历中改动
 * 被遍历的集合（设计文档 §3.4）。
 */
function update(entity, dt, context) {
  const service = context?.minecarts;
  if (!service || !context?.world) return entity.state;
  const { state, deferred, liftPlayer } = planMinecartStep({
    state: entity.state, dt, world: context.world,
    registry: context.registry ?? context.world.registry,
    service, selfId: entity.id, player: context.player ?? null,
  });
  if (deferred.length > 0) service.queueDeferred(deferred);
  if (liftPlayer !== null) service.liftPlayer(liftPlayer);
  return state;
}

export const minecartDefinition = Object.freeze({
  create: createState,
  update,
  raycastAabb: (state, origin, dir, maxDist) =>
    raycastAabbSlab(state, origin, dir, maxDist, MINECART_AABB),
  /** 持久 snapshot：只含 4 个字段（瞬态的 pendingTargetCell/linked 不入档） */
  serialize(state) {
    const s = createState(state);
    if (!s) return null;
    return {
      position: s.position,
      orientation: s.orientation,
      movementState: s.movementState,
      lastTrack: s.lastTrack,
    };
  },
  deserialize(raw) {
    if (!raw || typeof raw !== 'object') return null;
    return createState({
      position: raw.position,
      orientation: raw.orientation,
      movementState: raw.movementState,
      lastTrack: raw.lastTrack,
    });
  },
});

/**
 * 矿车玩法入口（设计文档 §1.2）。
 *
 * **不持有第二份实体集合**（红线 1）：state 权威在 `EntityManager`，本类只持有
 * ① 派生位置索引 `Map<"x,y,z", id>`（可 `syncIndex()` 全量重建）；
 * ② 每帧瞬态（reservations / deferred 队列 / 抬玩家意图）。
 */
export class MinecartService {
  /**
   * @param {{entities: import('../entity-manager.js').EntityManager, world: object,
   *          registry: object,
   *          persistence?: {entitiesCache: Map, flushEntities: Function}|null}} deps
   */
  constructor({ entities, world, registry, persistence = null }) {
    this.entities = entities;
    this.world = world;
    this.registry = registry;
    this.persistence = persistence;
    /** 派生位置索引：`"x,y,z"` → id（floor 基，拾取/乘坐/放置占用判定用） */
    this._index = new Map();
    /**
     * 派生 round 基索引：`"round(x),floor(y),round(z)"` → id。
     * ⚠️ **`planMinecartStep` 的前方车查询走 round 基**（`carInFront` 优先调 `carAtRound`），
     * 因为 `frontX = round(position)+dir` 是 round 基 —— 用 floor 基索引查会漏（fix round 2
     * 实测：两车互相穿过）。两份索引都从 EntityManager 派生，`syncIndex()` 一起重建。
     */
    this._roundIndex = new Map();
    /**
     * 帧前快照（`beginFrame()` 捕获）：`Array<{id, state}>`。
     * ⚠️ **这是「顺序无关」的关键**（fix round 2 实测）：`EntityManager.update` 里
     * `entity.state = next` 立即生效，若跨车读取实时 state，先跑的车停下后，后跑的车同帧
     * 看到它已 idle → `isHeadOn` 早退 false → 走「激活静止车」把刚停的车重新推走
     * （[a,b] ❌ / [b,a] ✅ —— 行为依赖遍历顺序）。`planMinecartStep` 的 `frameView()`
     * **优先读 `carsView()`**；若本方法缺失会回落到 `cars()`（实时 state）→ 顺序依赖悄悄复活。
     * 故 **`carsView()` 必须实现，不得省略**。
     */
    this._frameView = [];
    /** 每帧目标格预占位：`"x,y,z"` → id（mc-lite frameReservations 同物） */
    this.reservations = new Map();
    /** 跨车写入待生效队列 */
    this._deferred = [];
    /** 本帧「把玩家脚底抬到 y」的意图（game.js 消费后清空） */
    this.pendingPlayerLift = null;
  }

  /**
   * 每帧开始：清瞬态 + **捕获帧前快照**。
   * ⚠️ 快照必须在 `entities.update(...)` **之前**捕获（game.js 的帧序保证），
   * 否则 `carsView()` 读到的是半更新状态 → 顺序无关性失效。
   */
  beginFrame() {
    this.reservations.clear();
    this._deferred.length = 0;
    this.pendingPlayerLift = null;
    // 帧前快照：只存 id + state 引用（state 在本帧内会被替换成新对象，引用本身不被改写）
    this._frameView = [];
    for (const entity of this.entities.entities()) {
      if (entity.type === MINECART_TYPE) this._frameView.push({ id: entity.id, state: entity.state });
    }
  }

  /**
   * 帧前快照视图（`planMinecartStep` 的 `frameView()` 优先消费）。
   * ⚠️ **不得省略本方法** —— 缺失会让 `frameView()` 回落到 `cars()`（实时 state），
   * 顺序依赖悄悄复活（见 `_frameView` 字段注释）。
   * @returns {Array<{id: string, state: object}>}
   */
  carsView() { return this._frameView; }

  /**
   * round 基前方车查询（`planMinecartStep` 的 `carInFront()` 优先消费）。
   * ⚠️ **不得回落到 floor 基的 `carAt`** —— 两者不同源，混用会让偶数间距的相向车互相穿过
   * （fix round 2 实测的第四机制）。
   * @returns {{id: string, state: object}|null}
   */
  carAtRound(x, y, z) {
    const id = this._roundIndex.get(roundKey(x, y, z));   // roundKey 是同文件模块私有函数
    if (!id) return null;
    // ⚠️ **必须从帧前快照 `_frameView` 返回，不得返回实时 state**（controller 实测裁定）：
    // 若返回 `entities.get(id).state`（实时），先跑的车停下后，后跑的车同帧查到它已 idle
    // → isHeadOn 早退 → 走「激活静止车」把刚停的车重新推走（[a,b] ❌ / [b,a] ✅ ——
    // 顺序依赖复活）。返回快照则两车看到彼此「都还在动」→ 各自判出相向 → 都停。
    // 与 `carsView()` 同源（都是 `_frameView`），保证跨车读取口径一致。
    return this._frameView.find((e) => e.id === id) ?? null;
  }

  /** definition.update 调用：登记跨车写入意图 */
  queueDeferred(list) {
    for (const item of list) this._deferred.push(item);
  }

  /** definition.update 调用：登记抬玩家意图（多车同帧取最高值） */
  liftPlayer(y) {
    if (this.pendingPlayerLift === null || y > this.pendingPlayerLift) this.pendingPlayerLift = y;
  }

  /**
   * 统一生效跨车写入。**必须在 `entities.update(...)` 之后调**（设计文档 §3.4）。
   * 每条 patch 都经 `createState` 重建全新 state（M6 约束）。
   * @returns {number} 生效条数
   */
  applyDeferred() {
    let n = 0;
    const queue = this._deferred;
    this._deferred = [];
    for (const { id, patch } of queue) {
      const entity = this.entities.get(id);
      if (!entity || entity.type !== MINECART_TYPE) continue;
      const next = createState({ ...entity.state, ...patch });
      if (!next) continue;
      entity.state = next;
      n++;
    }
    return n;
  }

  /**
   * **每帧全量重建位置索引**（game.js 在 `applyDeferred()` 之后调）。
   * 为什么全量而非增量：50 辆车 × 每帧一次可忽略，且不会漏 —— 增量要在 definition
   * 里回调 service，把同构层与玩法入口耦合成环。不同步会让 `carAt` 读到过期格
   * （前方车判定失效 → 车互相穿过）。
   * @returns {number} 索引条目数
   */
  syncIndex() {
    this._index.clear();
    this._roundIndex.clear();
    for (const entity of this.entities.entities()) {
      if (entity.type !== MINECART_TYPE) continue;
      const [x, y, z] = entity.state.position;
      this._index.set(cellKey(x, y, z), entity.id);
      // round 基索引（前方车查询用）—— 与 floor 基索引同时重建，不得只建一份
      this._roundIndex.set(roundKey(x, y, z), entity.id);
    }
    return this._index.size;
  }

  /** 全局矿车数（**含未加载 column 的**）—— 上限判定唯一来源（M7 活跃约束）。 */
  count() {
    const loaded = new Set();
    for (const entity of this.entities.entities()) {
      if (entity.type === MINECART_TYPE) loaded.add(entity.id);
    }
    let unloaded = 0;
    if (this.persistence?.entitiesCache) {
      for (const [id, snapshot] of this.persistence.entitiesCache) {
        if (snapshot?.type === MINECART_TYPE && !loaded.has(id)) unloaded++;
      }
    }
    return loaded.size + unloaded;
  }

  /** 只读枚举（`planMinecartStep` 的声明冲突分支与渲染层共用）。 */
  cars() {
    const out = [];
    for (const entity of this.entities.entities()) {
      if (entity.type === MINECART_TYPE) out.push({ id: entity.id, state: entity.state });
    }
    return out;
  }

  /** 位置索引查询。@returns {{id:string, state:object}|null} */
  carAt(x, y, z) {
    const id = this._index.get(cellKey(x, y, z));
    if (!id) return null;
    const entity = this.entities.get(id);
    return entity ? { id: entity.id, state: entity.state } : null;
  }

  /**
   * 放置矿车（设计文档 §4.1）。预检顺序：no-column → not-air → no-track → occupied → limit。
   * ⚠️ 任何失败都在 `spawn` 之前返回 —— 失败路径零副作用。
   * @param {{cell: [number,number,number], orientation?: number|null}} req
   *        `orientation` 缺省时取下方铁轨的 meta 朝向（mc-lite `getTrackOrientation`）
   */
  place({ cell, orientation = null }) {
    const [x, y, z] = cell;
    if (!this.world.hasColumn(Math.floor(x / 16), Math.floor(z / 16))) {
      return { ok: false, reason: 'no-column' };
    }
    if (this.world.getBlockId(x, y, z) !== 0) return { ok: false, reason: 'not-air' };
    if (!isTrackBlock(this.world.getBlockId(x, y - 1, z), this.registry)) {
      return { ok: false, reason: 'no-track' };
    }
    if (this._index.has(cellKey(x, y, z))) return { ok: false, reason: 'occupied' };
    if (this.count() >= MINECART.maxMinecarts) return { ok: false, reason: 'limit' };

    // 朝向：缺省取铁轨 meta，再按可用轨道方向修正（mc-lite `createMinecart` 的 bestDir）
    let orient = orientation ?? this.world.getBlockMeta(x, y - 1, z);
    const aligned = alignToTrack(this.world, this.registry, orient, x, y, z);
    if (aligned !== null) orient = aligned;

    const id = this._nextId();
    const entity = this.entities.spawn({
      id,
      type: MINECART_TYPE,
      state: createState({
        position: [x, y, z], orientation: orient, movementState: MOVEMENT.IDLE,
        lastTrack: [x, y, z],
      }),
      persistent: true,   // 持久实体：白拿 M5 的写盘/卸载/清档生命周期
    });
    if (!entity) return { ok: false, reason: 'occupied' };   // id 撞车（理论不可达）
    this._index.set(cellKey(x, y, z), id);
    this._roundIndex.set(roundKey(x, y, z), id);   // 两份索引必须同时维护（否则前方车查询漏车）
    // 显式状态变化 → 立即 flush（M5 规格 §3 的 flush 时机；不 await，失败只记诊断）
    if (this.persistence?.flushEntities) {
      Promise.resolve(this.persistence.flushEntities()).catch((err) => {
        console.warn('[minecart] flushEntities failed:', err);
      });
    }
    return { ok: true, id };
  }

  /** 拾取：断连挂 + despawn + 清索引。**不加回背包**（创造模式口径，设计文档 §6 偏离 3）。 */
  pickUp(id) {
    const entity = this.entities.get(id);
    if (!entity || entity.type !== MINECART_TYPE) return false;
    this.breakLinks(id);
    return this.destroy(id);
  }

  /**
   * 激活（ctrl+左键）。**可走才激活**（`alignToTrack` 返回 null 即无邻轨 → 拒绝），
   * 并按 `findLinked` 带出整列车（mc-lite `activateLinkedMinecarts` 语义）。
   * @param {string} id @param {boolean} backward shift 键 → 后退
   * @returns {boolean}
   */
  activate(id, backward = false) {
    const entity = this.entities.get(id);
    if (!entity || entity.type !== MINECART_TYPE) return false;
    const [x, y, z] = entity.state.position;
    const movement = backward ? MOVEMENT.BACKWARD : MOVEMENT.FORWARD;
    const aligned = alignToTrack(this.world, this.registry, entity.state.orientation,
      Math.floor(x), Math.floor(y), Math.floor(z));
    if (aligned === null) return false;   // 无可用轨道 → 不激活

    const byId = new Map();
    for (const c of this.cars()) byId.set(c.id, c.state);
    const linkedIds = findLinked(byId, id);
    for (const linkedId of linkedIds) {
      const linked = this.entities.get(linkedId);
      if (!linked) continue;
      // 领头车用 align 结果；连挂车按「领头朝向优先，其次反向，其次任一可用」
      let orient = aligned;
      if (linkedId !== id) {
        const [lx, ly, lz] = linked.state.position;
        const dirs = availableTrackDirections(this.world, this.registry,
          Math.floor(lx), Math.floor(ly), Math.floor(lz));
        if (dirs.includes(aligned)) orient = aligned;
        else if (dirs.includes((aligned + 2) % 4)) orient = (aligned + 2) % 4;
        else if (dirs.length > 0) orient = dirs[0];
        else continue;   // 该车无可用轨道 → 不激活它
      }
      linked.state = createState({
        ...linked.state, orientation: orient, movementState: movement,
        linked: linkedIds.filter((other) => other !== linkedId),
        lastTrack: linked.state.lastTrack ?? [Math.floor(linked.state.position[0]),
          Math.floor(linked.state.position[1]), Math.floor(linked.state.position[2])],
      });
    }
    return true;
  }

  /** 断开连挂：连挂车全部停 + 清 linked（mc-lite `breakLinks`）。 */
  breakLinks(id) {
    const entity = this.entities.get(id);
    if (!entity || entity.type !== MINECART_TYPE) return;
    for (const linkedId of entity.state.linked ?? []) {
      const linked = this.entities.get(linkedId);
      if (!linked) continue;
      linked.state = createState({
        ...linked.state, movementState: MOVEMENT.IDLE,
        linked: (linked.state.linked ?? []).filter((other) => other !== id),
      });
    }
  }

  /** 移除矿车（拾取 / 爆炸共用）。@returns {boolean} */
  destroy(id) {
    const entity = this.entities.get(id);
    if (!entity || entity.type !== MINECART_TYPE) return false;
    const key = cellKey(...entity.state.position);
    if (this.entities.despawn(id, 'minecart-destroyed')) {
      if (this._index.get(key) === id) this._index.delete(key);
      const rKey = roundKey(...entity.state.position);
      if (this._roundIndex.get(rKey) === id) this._roundIndex.delete(rKey);
      return true;
    }
    return false;
  }

  /**
   * 爆炸半径内摧毁（mc-lite 爆炸段语义）。
   * @param {[number,number,number]} center **方块格坐标**（内部 +0.5 换算块中心）
   * @param {number} [radius] @returns {number} 摧毁数
   */
  destroyInRadius(center, radius = MINECART.explosionRadius) {
    const cx = center[0] + 0.5, cy = center[1] + 0.5, cz = center[2] + 0.5;
    const victims = [];
    for (const c of this.cars()) {
      const [px, py, pz] = c.state.position;
      const dx = px + 0.5 - cx;
      const dy = py + MINECART.explosionOffsetY - cy;
      const dz = pz + 0.5 - cz;
      if (Math.hypot(dx, dy, dz) <= radius) victims.push(c.id);
    }
    for (const victimId of victims) this.destroy(victimId);
    return victims.length;
  }

  /**
   * 乘坐候选：玩家脚下格是否有车，且玩家脚底在车顶 ±容差内（mc-lite `updateMinecartRiding`）。
   * @param {[number,number,number]} playerPos 玩家脚底
   * @returns {{id:string, state:object}|null}
   */
  ridingCarFor(playerPos) {
    const [px, py, pz] = playerPos;
    // mc-lite：`feetY = floor(position.y - 0.1)`
    const c = this.carAt(Math.floor(px), Math.floor(py - 0.1), Math.floor(pz));
    if (!c) return null;
    const topY = c.state.position[1] + MINECART.rideHeight;
    if (Math.abs(py - topY) >= MINECART.rideBindTolerance) return null;
    return c;
  }

  /** 确定性 id（红线 2：不用 Math.random）。取已加载 + cache 的最大后缀 +1。 */
  _nextId() {
    let max = 0;
    const scan = (id) => {
      const n = Number.parseInt(String(id).replace(/^minecart-/, ''), 10);
      if (Number.isFinite(n) && n > max) max = n;
    };
    for (const entity of this.entities.entities()) {
      if (entity.type === MINECART_TYPE) scan(entity.id);
    }
    if (this.persistence?.entitiesCache) {
      for (const [id, snapshot] of this.persistence.entitiesCache) {
        if (snapshot?.type === MINECART_TYPE) scan(id);
      }
    }
    return `minecart-${max + 1}`;
  }

  /** 反向释放（Game.dispose）。 */
  dispose() {
    for (const c of this.cars()) this.entities.despawn(c.id, 'dispose');
    this._index.clear();
    this.reservations.clear();
    this._deferred.length = 0;
  }
}
```

```js
// src/render/minecart-renderer.js — 矿车渲染（2 个 InstancedMesh，设计文档 §5）
//
// **为什么是 2 个 InstancedMesh 而不是每车 5 个 mesh**：mc-lite 也是 InstancedMesh，
// 本仓库照 M6/M8 手法：车斗 1 个 + 车轮 1 个（容量 ×4），差集驱动 slot，
// 零实例时 `visible=false`（否则恒增 2 个 draw call —— M6 实测教训）。
//
// ⚠️ **车斗纹理是运行时 canvas 生成**（用户选定，设计文档 §6 偏离 5）：无指纹门禁保护，
// 纹理算法改动靠 Tier 4 像素实测兜底（记入 roadmap 遗留 TODO）。
import * as THREE from 'three';
import { MINECART, MINECART_TYPE, rotationAngleOf } from '../entities/minecarts/minecart-config.js';

// 复用的临时对象（避免每帧分配 —— 50 车 × 5 实例 × 60fps）
const _dummy = new THREE.Object3D();
const _zero = new THREE.Matrix4().makeScale(0, 0, 0);

/** 车轮相对车中心的四个偏移（mc-lite `updateWheelMatrices` 的 wheelOffsets 逐位）。 */
const WHEEL_OFFSETS = Object.freeze([
  Object.freeze({ x: -MINECART.trackWidth / 2, z: MINECART.wheelbase / 2 }),   // 左前
  Object.freeze({ x: MINECART.trackWidth / 2, z: MINECART.wheelbase / 2 }),    // 右前
  Object.freeze({ x: -MINECART.trackWidth / 2, z: -MINECART.wheelbase / 2 }),  // 左后
  Object.freeze({ x: MINECART.trackWidth / 2, z: -MINECART.wheelbase / 2 }),   // 右后
]);

/**
 * 倒梯形开口车斗几何（mc-lite `createTrapezoidGeometry` 顶点逐位移植）。
 * 顶 0.9×0.9、底缩 0.8 倍、高 0.8、**无顶面**（开口车斗）、5 个四边形。
 * 几何中心在原点（渲染时按 `position + (0.5, bodyHeight/2 + wheelRadius, 0.5)` 摆放）。
 */
export function createBodyGeometry() {
  const tw = MINECART.bodyWidth / 2;
  const td = MINECART.bodyDepth / 2;
  const bw = MINECART.bodyWidth * MINECART.bodyShrinkRatio / 2;
  const bd = MINECART.bodyDepth * MINECART.bodyShrinkRatio / 2;
  const h = MINECART.bodyHeight / 2;
  const p = {
    bbl: [-bw, -h, -bd], bbr: [bw, -h, -bd], bfr: [bw, -h, bd], bfl: [-bw, -h, bd],
    tbl: [-tw, h, -td], tbr: [tw, h, -td], tfr: [tw, h, td], tfl: [-tw, h, td],
  };
  const positions = [];
  const uvs = [];
  const indices = [];
  const addFace = (a, b, c, d) => {
    const base = positions.length / 3;
    for (const v of [a, b, c, d]) positions.push(v[0], v[1], v[2]);
    uvs.push(0, 0, 1, 0, 1, 1, 0, 1);   // 统一四边形 UV（mc-lite 同口径）
    indices.push(base, base + 1, base + 2, base, base + 2, base + 3);
  };
  addFace(p.bbl, p.bbr, p.bfr, p.bfl);   // 底
  addFace(p.bfl, p.bfr, p.tfr, p.tfl);   // 前
  addFace(p.bbr, p.bbl, p.tbl, p.tbr);   // 后
  addFace(p.bbl, p.bfl, p.tfl, p.tbl);   // 左
  addFace(p.bfr, p.bbr, p.tbr, p.tfr);   // 右
  const geometry = new THREE.BufferGeometry();
  geometry.setAttribute('position', new THREE.Float32BufferAttribute(positions, 3));
  geometry.setAttribute('uv', new THREE.Float32BufferAttribute(uvs, 2));
  geometry.setIndex(indices);
  geometry.computeVertexNormals();
  return geometry;
}

/**
 * 车斗纹理（mc-lite `createMinecartBodyTexture` 逐行移植：渐变 + 上沿压边 + 底部阴影
 * + 420 金属噪点 + 竖向拉丝）。⚠️ **运行时生成 → 无指纹门禁**（设计文档 §6 偏离 5）。
 * @returns {THREE.CanvasTexture|null} 无 2D context 时返回 null（材质退回纯色）
 */
export function createMinecartBodyTexture() {
  const size = MINECART.textureSize;
  const canvas = document.createElement('canvas');
  canvas.width = size;
  canvas.height = size;
  const ctx = canvas.getContext('2d');
  if (!ctx) return null;
  const gradient = ctx.createLinearGradient(0, 0, 0, size);
  gradient.addColorStop(0, '#a7afb8');
  gradient.addColorStop(0.5, '#c0c6ce');
  gradient.addColorStop(1, '#8f98a2');
  ctx.fillStyle = gradient;
  ctx.fillRect(0, 0, size, size);
  ctx.fillStyle = 'rgba(58, 63, 70, 0.8)';                       // 顶部深色压边
  ctx.fillRect(0, 0, size, Math.floor(size * 0.14));
  ctx.fillStyle = 'rgba(40, 45, 52, 0.2)';                       // 底部阴影
  ctx.fillRect(0, Math.floor(size * 0.85), size, Math.floor(size * 0.15));
  for (let i = 0; i < 420; i++) {                                 // 金属噪点
    const x = (Math.random() * size) | 0;
    const y = (Math.random() * size) | 0;
    const v = 155 + ((Math.random() * 60) | 0);
    const alpha = 0.1 + Math.random() * 0.2;
    ctx.fillStyle = `rgba(${v}, ${v}, ${v}, ${alpha.toFixed(3)})`;
    ctx.fillRect(x, y, 1, 1);
  }
  ctx.strokeStyle = 'rgba(235, 240, 245, 0.08)';                  // 竖向拉丝
  for (let x = 0; x < size; x += 6) {
    ctx.beginPath();
    ctx.moveTo(x, 0);
    ctx.lineTo(x, size);
    ctx.stroke();
  }
  const texture = new THREE.CanvasTexture(canvas);
  texture.colorSpace = THREE.SRGBColorSpace;
  texture.wrapS = THREE.RepeatWrapping;
  texture.wrapT = THREE.RepeatWrapping;
  texture.magFilter = THREE.NearestFilter;
  texture.minFilter = THREE.LinearMipmapLinearFilter;
  texture.generateMipmaps = true;
  texture.needsUpdate = true;
  return texture;
}

export class MinecartRenderer {
  /**
   * @param {{scene: THREE.Scene, maxActive?: number}} deps
   *        `maxActive` 缺省 = `MINECART.maxMinecarts`（**必须从 config 派生**，红线 1）
   */
  constructor({ scene, maxActive = MINECART.maxMinecarts }) {
    this.scene = scene;
    this.maxActive = maxActive;
    this._texture = createMinecartBodyTexture();
    this._bodyGeometry = createBodyGeometry();
    this._wheelGeometry = new THREE.CylinderGeometry(
      MINECART.wheelRadius, MINECART.wheelRadius, MINECART.wheelHeight, 8);
    // ⚠️ **材质用 `MeshBasicMaterial`（unlit）而非 mc-lite 的 `MeshStandardMaterial`** ——
    // mc-heavy 全场景是 unlit 设计，灯光只为 PBR 武器模型而设（`zombie-renderer.js:32` 同口径：
    // 用受光材质会让实体吃到为枪标定的 2.3 环境光强度 → 偏亮且随日夜灯光漂移）。
    // 故 mc-lite 的 metalness/roughness 两个字段在本仓库**无消费点**（保留在 config 里仅作
    // mc-lite 出处记录，不参与渲染）—— 与「床材质的 offset/rotation 是死字段」同一类事实。
    this._bodyMaterial = new THREE.MeshBasicMaterial({
      color: MINECART.bodyColor,
      map: this._texture,
      side: THREE.DoubleSide,   // 开口车斗：内壁也要可见（mc-lite 同口径）
    });
    this._wheelMaterial = new THREE.MeshBasicMaterial({ color: MINECART.wheelColor });
    this.meshes = {
      body: this._createMesh(this._bodyGeometry, this._bodyMaterial, maxActive, 'minecart:body'),
      wheel: this._createMesh(this._wheelGeometry, this._wheelMaterial, maxActive * 4, 'minecart:wheel'),
    };
    /** @type {Map<string, number>} minecartId → slot（差集驱动，炮塔同手法） */
    this._slots = new Map();
    this._nextSlot = 0;
  }

  _createMesh(geometry, material, count, name) {
    const mesh = new THREE.InstancedMesh(geometry, material, count);
    mesh.name = name;                 // 受控标识：测试与调试据此定位节点
    mesh.instanceMatrix.setUsage(THREE.DynamicDrawUsage);
    mesh.frustumCulled = false;       // 实例池包围球按 slot 0 算 → 会被误剔除（炮塔同口径）
    mesh.visible = false;             // ⚠️ 无活跃矿车时不提交渲染
    for (let i = 0; i < count; i++) mesh.setMatrixAt(i, _zero);
    mesh.instanceMatrix.needsUpdate = true;
    this.scene.add(mesh);
    return mesh;
  }

  /** 只读 slot 数（测试钩子）。 */
  slotCount() { return this._slots.size; }

  /**
   * 发布 pose（只读 state → 实例矩阵）。**差集驱动 slot**：新 id 分配、消失 id 归还。
   * ⚠️ 渲染层不回写 state（M5 约束）。
   * @param {Iterable<import('../entities/entity-manager.js').Entity>} entities
   */
  sync(entities) {
    const live = new Set();
    for (const entity of entities) {
      if (entity.type !== MINECART_TYPE) continue;
      const id = entity.id;
      live.add(id);
      let slot = this._slots.get(id);
      if (slot === undefined) {
        slot = this._nextSlot;
        this._nextSlot = (this._nextSlot + 1) % this.maxActive;   // 池满覆盖最旧（纯视觉）
        this._slots.set(id, slot);
      }
      const [x, y, z] = entity.state.position;
      // ⚠️ **原点换算 +0.5**（块底角 → 块中心；CLAUDE.md 活跃约束）
      const px = x + 0.5;
      const pz = z + 0.5;
      const ry = rotationAngleOf(entity.state.orientation);
      // 车斗：y = 车Y + bodyHeight/2 + wheelRadius（mc-lite `updateBodyMatrix`）
      _dummy.position.set(px, y + MINECART.bodyHeight / 2 + MINECART.wheelRadius, pz);
      _dummy.rotation.set(0, ry, 0);
      _dummy.scale.set(1, 1, 1);
      _dummy.updateMatrix();
      this.meshes.body.setMatrixAt(slot, _dummy.matrix);
      // 4 个车轮（mc-lite `updateWheelMatrices`：rotation = (0, ry + π/2, π/2)）
      for (let w = 0; w < WHEEL_OFFSETS.length; w++) {
        const offset = WHEEL_OFFSETS[w];
        _dummy.position.set(px + offset.x, y + MINECART.wheelRadius, pz + offset.z);
        _dummy.rotation.set(0, ry + Math.PI / 2, Math.PI / 2);
        _dummy.updateMatrix();
        this.meshes.wheel.setMatrixAt(slot * 4 + w, _dummy.matrix);
      }
    }
    // 归还消失 id 的 slot（清矩阵，不留残影）
    for (const [id, slot] of [...this._slots]) {
      if (live.has(id)) continue;
      this.meshes.body.setMatrixAt(slot, _zero);
      for (let w = 0; w < 4; w++) this.meshes.wheel.setMatrixAt(slot * 4 + w, _zero);
      this._slots.delete(id);
    }
    this.meshes.body.instanceMatrix.needsUpdate = true;
    this.meshes.wheel.instanceMatrix.needsUpdate = true;
    const anyActive = this._slots.size > 0;
    this.meshes.body.visible = anyActive;
    this.meshes.wheel.visible = anyActive;
  }

  dispose() {
    for (const key of ['body', 'wheel']) {
      this.scene.remove(this.meshes[key]);
      this.meshes[key].dispose();
    }
    this._bodyGeometry.dispose();
    this._wheelGeometry.dispose();
    this._bodyMaterial.dispose();
    this._wheelMaterial.dispose();
    if (this._texture) this._texture.dispose();
    this._slots.clear();
  }
}
```

- [ ] **Step 6: 乘坐逻辑（`update` 内）**

在 `update(dt)` 的 `this._acc += dt;` 之前加乘坐推进：

```js

```

并加方法：

```js
  /**
   * 矿车乘坐（设计文档 §4.4）。在物理步之前跑 —— 跟随读上帧车位（mc-lite 同序）。
   * 绑定：站在车顶 ±容差内且不在重绑冷却；跟随：按车位移增量推玩家（y 锁车顶）；
   * 下车：空格（起跳 + 重绑冷却）或水平偏离超阈值。
   */
  _updateMinecartRiding(dt) {
    if (!this.minecarts) return;
    if (this._remountCooldown > 0) this._remountCooldown -= dt;
    const p = this.physics.pos;

    if (this.ridingMinecartId) {
      const entity = this.minecarts.entities.get(this.ridingMinecartId);
      // 车已消失（拾取/爆炸/卸载）→ 立即解绑
      if (!entity || entity.type !== MINECART_TYPE) {
        this.ridingMinecartId = null;
        this._lastRidePos = null;
        return;
      }
      const [cx, cy, cz] = entity.state.position;
      // 跟随增量（mc-lite：dx/dz = 车位 − 上帧车位）
      if (this._lastRidePos) {
        p.x += cx - this._lastRidePos[0];
        p.z += cz - this._lastRidePos[2];
      }
      p.y = cy + MINECART.rideHeight;
      this.physics.vel.y = 0;
      this._lastRidePos = [cx, cy, cz];
      // 水平偏离超阈值 → 自动下车
      if (Math.abs(p.x - (cx + 0.5)) > MINECART.dismountDeviation
          || Math.abs(p.z - (cz + 0.5)) > MINECART.dismountDeviation) {
        this.ridingMinecartId = null;
        this._lastRidePos = null;
      }
      // 空格下车（边沿触发）
      if (this.keys.has('Space') && this._spaceReleased) {
        this._spaceReleased = false;
        this.physics.dismountJump();   // 下车起跳（常量单一权威在 physics.js，不得写 10.0 字面量）
        this.ridingMinecartId = null;
        this._lastRidePos = null;
        this._remountCooldown = MINECART.remountCooldown;
      }
      return;
    }

    // 未绑定：检测脚下是否有车（重绑冷却内不绑）
    if (this._remountCooldown <= 0) {
      const car = this.minecarts.ridingCarFor([p.x, p.y, p.z]);
      if (car) {
        this.ridingMinecartId = car.id;
        this._lastRidePos = [...car.state.position];
      }
    }
    // 空格边沿状态复位
    if (!this.keys.has('Space')) this._spaceReleased = true;
  }
```

⚠️ **乘坐期间要跳过自主移动与重力**：`_applyInput` 与 `physics.step` 会把玩家从车上推走/拉下去。在 `update(dt)` 的 60Hz 循环处改为：

```js

    while (this._acc >= step && n < 5) {

        this._applyInput();
        this.physics.step(step);

```

⚠️ **偏离判定用 `cx + 0.5`（车中心）是有意偏离 mc-lite，已实测核实**：
mc-lite 写的是 `deviationX = |player.x − minecart.position.x|`（从**块角**量），而它的绑定判据
是 `getMinecartAt(floor(player.x), …)` → 玩家必在 `[cx, cx+1)` 内。两者叠加的后果：玩家站在
车的**远半格**（如 cx+0.7）时 deviation=0.7 > 0.6 → **人还在车上就被自动下车**。
本仓库从车中心（`position + 0.5`，与渲染原点换算同源）量：玩家站在 cx+0.7 时 deviation=0.2
→ 保持乘坐；走到 cx+1.2（真离车）时 0.7 > 0.6 → 下车。**符合设计文档 §4.4 的意图**
（「水平偏离车中心 > 0.6」），不是 mc-lite 的字面行为 —— 记入偏离表。

- [ ] **Step 6b: 补乘坐跟随的障碍检测（设计文档 §4.4 明确要求，Step 6 漏了）**

⚠️ **这是 spec 合规缺口，不是可选优化**：设计文档 §4.4 明写「跟随：绑定后按车位移增量推玩家
（**分轴，各轴单独做障碍检测** —— 障碍判定排除自己乘坐的这辆车）」，对应 mc-lite
`updateMinecartRiding` 的 `checkAABBExcludeMinecart`。Task 6 的实现（`player.js:300-301`）是
`p.x += dx; p.z += dz;` —— **无碰撞解算**，且乘坐期间 `physics.step` 被跳过。
后果（Task 6 评审员 ⚠️ 指出）：车穿过低矮隧道会把 1.8 高的玩家 AABB 埋进实心块，
下车后每次 `_moveAxis` 都碰撞、二分收敛到零位移 → **玩家卡死**。

**修法**：在 `src/player/physics.js` 加一个公开方法（与 `_collides` 同判据，但可指定位置）：

```js
  /**
   * 指定位置的玩家 AABB 是否与实心方块重叠（乘坐跟随的分轴障碍检测用）。
   * ⚠️ 与 `_collides()` 同判据（`world.isSolid` + PLAYER_WIDTH/PLAYER_HEIGHT），但
   * **不读 `this.pos`** —— 乘坐跟随要「先试探再决定写不写」，不能先改 pos 再回滚。
   * 设计文档 §4.4：「分轴，各轴单独做障碍检测」。
   * @param {number} x @param {number} y @param {number} z 候选脚底中心
   * @returns {boolean}
   */
  collidesAt(x, y, z) {
    const w = this.world;
    const hw = PLAYER_WIDTH / 2;
    const x0 = Math.floor(x - hw), x1 = Math.floor(x + hw);
    const y0 = Math.floor(y), y1 = Math.floor(y + PLAYER_HEIGHT - EPSILON);
    const z0 = Math.floor(z - hw), z1 = Math.floor(z + hw);
    for (let bx = x0; bx <= x1; bx++) {
      for (let by = y0; by <= y1; by++) {
        for (let bz = z0; bz <= z1; bz++) {
          if (w.isSolid(bx, by, bz)) return true;
        }
      }
    }
    return false;
  }
```

然后把 `player.js` 的 `_updateMinecartRiding` 跟随段（`if (this._lastRidePos) { p.x += …; p.z += …; }`）
改成**分轴试探**（mc-lite `canMoveX`/`canMoveZ` 同口径）：

```js

      // ⚠️ **分轴障碍检测**（设计文档 §4.4）：各轴单独试探，被挡的那一轴不推进 ——
      // 否则车穿过低矮隧道会把玩家 AABB 埋进实心块，下车后 `_moveAxis` 二分收敛到
      // 零位移 → 玩家卡死。y 仍锁车顶（车顶净空由矿车移动的 ⑥/⑦ 分支保证：
      // 前方玩家头顶无空间则停车，有空间则抬玩家）。
      if (this._lastRidePos) {
        const dx = cx - this._lastRidePos[0];
        const dz = cz - this._lastRidePos[2];
        const topY = cy + MINECART.rideHeight;
        if (dx !== 0 && !this.physics.collidesAt(p.x + dx, topY, p.z)) p.x += dx;
        if (dz !== 0 && !this.physics.collidesAt(p.x, topY, p.z + dz)) p.z += dz;
```

```js
/**
 * 在玩家附近找一段可铺轨的地面并铺一条直轨，返回轨道上方格（矿车放置点）。
 * ⚠️ 铺轨走 editor.setBlock（唯一世界写入入口），不用 world.setBlock 绕过 remesh。
 */
async function layTrackNearPlayer(page, length = 8) {
  return page.evaluate((len) => {
    const g = window.__MC_GAME__;
    const px = Math.floor(g.player.physics.pos.x);
    const pz = Math.floor(g.player.physics.pos.z);
    const trackId = g.registry.idOf('sand_train_track');
    for (let ox = px + 2; ox <= px + 30; ox++) {
      for (let oz = pz - 20; oz <= pz + 20; oz++) {
        if (!g.world.hasColumn(Math.floor(ox / 16), Math.floor(oz / 16))) continue;
        let groundY = null;
        for (let y = 90; y > -32; y--) {
          if (g.world.getBlockId(ox, y, oz) !== 0) { groundY = y; break; }
        }
        if (groundY === null) continue;
        // 轨道层（groundY+1）与其上方一格必须全空
        let clear = true;
        for (let i = 0; i < len && clear; i++) {
          const x = ox + i;
          if (!g.world.hasColumn(Math.floor(x / 16), Math.floor(oz / 16))) { clear = false; break; }
          if (g.world.getBlockId(x, groundY + 1, oz) !== 0) clear = false;
          if (g.world.getBlockId(x, groundY + 2, oz) !== 0) clear = false;
        }
        if (!clear) continue;
        for (let i = 0; i < len; i++) {
          g.editor.setBlock({ x: ox + i, y: groundY + 1, z: oz, id: trackId, meta: 0 });
        }
        return { cell: [ox + 1, groundY + 2, oz], trackY: groundY + 1 };
      }
    }
    return null;
  }, length);
}

test('乘坐穿低矮隧道：障碍检测阻止玩家被埋进实心块', async ({ page }) => {
  await boot(page);
  // ⚠️ **几何必须这样搭**（controller 实测核实）：车Y = groundY+2，玩家脚底 = 车Y+0.9，
  // 玩家高 1.8 → 身体跨 groundY+2 ~ groundY+4.7（含整数层 groundY+2/+3/+4）。
  // 若把天花板放在玩家绑定位置的正上方，**绑定瞬间就已嵌入** —— 障碍检测只拦移动，
  // 救不了已嵌入的状态。故正确测法：天花板**只盖隧道内部**，玩家在隧道口外绑定
  // （净空足够），车开进去时玩家跟随被挡 → 停在隧道口 → 偏离 > 0.6 自动下车。
  const r = await page.evaluate(async () => {
    const g = window.__MC_GAME__;
    const px = Math.floor(g.player.physics.pos.x);
    const pz = Math.floor(g.player.physics.pos.z);
    const trackId = g.registry.idOf('sand_train_track');
    const stoneId = g.registry.idOf('stone');
    // 找一段可铺 8 格轨的地面（前 2 格做隧道口，后 6 格盖天花板）
    let spot = null;
    for (let ox = px + 2; ox <= px + 20 && !spot; ox++) {
      for (let oz = pz - 10; oz <= pz + 10 && !spot; oz++) {
        if (!g.world.hasColumn(Math.floor(ox / 16), Math.floor(oz / 16))) continue;
        let groundY = null;
        for (let y = 90; y > -32; y--) {
          if (g.world.getBlockId(ox, y, oz) !== 0) { groundY = y; break; }
        }
        if (groundY === null) continue;
        let clear = true;
        for (let i = 0; i < 8 && clear; i++) {
          const x = ox + i;
          if (!g.world.hasColumn(Math.floor(x / 16), Math.floor(oz / 16))) { clear = false; break; }
          // 轨道层 + 上方 3 格净空（玩家高 1.8 站在车顶上需要）
          for (let dy = 1; dy <= 4; dy++) {
            if (g.world.getBlockId(x, groundY + dy, oz) !== 0) clear = false;
          }
        }
        if (clear) spot = { ox, oz, groundY };
      }
    }
    if (!spot) return { skipped: true };
    const { ox, oz, groundY } = spot;
    const cartY = groundY + 2;
    // 铺 8 格轨
    for (let i = 0; i < 8; i++) {
      g.editor.setBlock({ x: ox + i, y: groundY + 1, z: oz, id: trackId, meta: 0 });
    }
    // 天花板只盖隧道内部（i=2..7），高度 = groundY+3 —— 玩家身体跨 +2~+4.7，必被挡
    for (let i = 2; i < 8; i++) {
      g.editor.setBlock({ x: ox + i, y: groundY + 3, z: oz, id: stoneId });
    }
    // 车放在隧道口（i=0），玩家站在它顶上绑定（此处无天花板，净空足够）
    const { ok, id } = g.minecarts.place({ cell: [ox, cartY, oz] });
    if (!ok) return { skipped: true };
    g.player.physics.pos.x = ox + 0.5;
    g.player.physics.pos.y = cartY + 0.9;
    g.player.physics.pos.z = oz + 0.5;
    g.minecarts.activate(id, false);
    // 跑足够帧让车开进隧道（8 格 / 2 格每秒 = 4s，给 6s 余量）
    const t0 = performance.now();
    let maxPlayerY = -Infinity;
    let embeddedFrames = 0;
    while (performance.now() - t0 < 6000) {
      await new Promise((r) => requestAnimationFrame(r));
      const p = g.player.physics.pos;
      maxPlayerY = Math.max(maxPlayerY, p.y);
      // 嵌入判据：玩家身体（脚底~脚底+1.8）跨到的整数层里有实心块
      const y0 = Math.floor(p.y), y1 = Math.floor(p.y + 1.8 - 0.001);
      const x0 = Math.floor(p.x - 0.3), x1 = Math.floor(p.x + 0.3);
      const z0 = Math.floor(p.z - 0.3), z1 = Math.floor(p.z + 0.3);
      let embedded = false;
      for (let bx = x0; bx <= x1 && !embedded; bx++) {
        for (let by = y0; by <= y1 && !embedded; by++) {
          for (let bz = z0; bz <= z1 && !embedded; bz++) {
            if (g.world.isSolid(bx, by, bz)) embedded = true;
          }
        }
      }
      if (embedded) embeddedFrames++;
    }
    const carX = g.entities.get(id)?.state.position[0] ?? null;
    return {
      skipped: false,
      embeddedFrames,
      maxPlayerY,
      ceilingY: groundY + 3,
      playerY: g.player.physics.pos.y,
      playerX: g.player.physics.pos.x,
      riding: g.player.ridingMinecartId,
      carX,
      tunnelMouthX: ox + 0.5,
    };
  });
  if (r.skipped) test.skip(true, '找不到可铺轨的地面');
  // 核心断言：全程零帧嵌入（障碍检测生效）
  expect(r.embeddedFrames).toBe(0);
  // 车确实开进了隧道（否则用例是无效盲区 —— 恒真）
  expect(r.carX).toBeGreaterThan(r.tunnelMouthX + 2);
  // 玩家被挡在隧道口附近（没跟着车进去），且已自动下车
  expect(r.playerX).toBeLessThan(r.carX);
  expect(r.riding).toBeNull();
});
```
