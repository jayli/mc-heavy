# 空岛天空树 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 在空岛顶层按 mc-lite 的逐格 10% 概率确定性长出天空树（`sky_wood` + `sky_leaves`），并把 `sky_leaves` 的渲染通道从 `cutout` 修正为 `opaque`（方案 C）。

**Architecture:** 天空树是**体素方块**（写进 `column.blocks`），走既有 GEN → meshing → BatchedMesh 管线，**不新增 Worker、不新增渲染通道、不创建 entity、不引入结构中心缓存**。树层追加进 `applyStructuresToColumn` 阶段 2.5 的既有固定层序（云 → 岛体 → 树）。`sky_leaves` 的通道修正只改 `blocks-data.js` 一行声明 —— 它使 `opaqueTable[sky_leaves]` 从 0 变 1，从而让 `mesher.js:464` 的通用面剔除对叶-叶相邻面生效（**`mesher.js` 零改动**）。

**Tech Stack:** 纯 JavaScript（ES2022+ ESM）+ JSDoc，无 TS / 无 bundler；three r185.1（本地 `vendor/three/`）；浏览器内单测（`src/tests/`）+ Playwright（`tests/`）；WebGPU 唯一后端。

**Spec:** `docs/superpowers/specs/2026-09-20-sky-tree-design.md` —— 计划里的所有数字与决策依据都来自该 spec 的实测章节（§4/§5），执行者须同时读 spec。

> ⚠️ **本计划与 spec 已按评审报告修正**（[`docs/superpowers/reviews/2026-09-20-sky-tree-review.md`](../reviews/2026-09-20-sky-tree-review.md)）：

## Global Constraints

- **语言/工具链**：纯 JavaScript（ES2022+ ES Modules）+ JSDoc，**禁止 TypeScript**，无编译/转译、无 bundler。
- **three 版本**：r185.1，本地 `vendor/three/`，import map 指向本地文件。**不做 WebGL2 降级**。
- **端口**：8081。
- **Worker 同构（红线 8/10）**：`src/gen/`、`src/voxel/`、`src/mesh/`、`src/workers/` 下**不得 import three**、不得自建 Worker（Worker 创建入口唯一 = `core/worker-pool.js`）。`sky-structures.js` 属 `src/gen/`，本计划新增的代码必须无 three / 无 DOM。
- **数据单一权威（红线 1）**：`blocks + meta + blockEntities` 是唯一权威；树只是往 `column.blocks` 写方块，**不得**新增结构中心缓存、不得存树的第二份数据、不得发跨 column 补刷。
- **确定性（红线 2）**：世界无预生成、无 `Math.random`。树的位置与形状只由 `(wx, wz, seed)` 推导，同 seed 同位置同形状、与加载顺序无关。
- **冻结数值（不得改动，除非实测撞破并按 spec §5.3 停下报告）**：
  - `SKY_TREE_CHANCE = 0.1`（mc-lite `Island.js:48` 的 `Math.random() < 0.1`）
  - `SKY_TREE_SALT = 113`（spec §3.1 程序化扫描确认空闲；**不能用 59**，59 落在云簇 frontier 的 `58..107` 区间内）
  - `CAPACITY`（`src/render/render-world.js:23-27`）三通道标定值**全部不动**
  - `§4.10` 的 `gpuVertexBytes < 150MiB` 冻结预算**不放宽**（`tests/m3-fullscene.spec.mjs:95`）
  - `docs/m3-baseline.*` 是冻结基线，**禁止提交其改动**（不带 `--check` 跑 bench 会自动重写它）
- **不需重跑的离线产物**：`npm run icons` 与 `npm run atlas` **都不跑** —— 图标指纹只含 `geometry` + tile 地址 + tile 像素 hash（**不含 `cullMode`**，实测核实 `tools/icon-fingerprint.mjs:118-134`），且本计划不改任何贴图像素（`sky_leaves` 的 alpha 230 保留不动）。
- **提交纪律**：Conventional Commits（`feat:` / `test:` / `refactor:` / `docs:`）。⚠️ **每个 Task 末尾的 commit step 须等用户明确指令才执行**（CLAUDE.md「未获明确指令不得自动提交」）—— 执行时若用户未授权，跳过 commit step 并在交付报告里列出待提交的改动清单。

/** 独立重算某岛的期望树干基点集合（不复用 writeSkyTrees 的实现路径） */
function expectedTrunkCells(cand) {
  const centerX = cand.originCx * 16 + 8, centerZ = cand.originCz * 16 + 8;
  const topY = cand.bottomY + cand.height;
  const r = islandLayerRadius(cand.radius, cand.height, cand.height); // === cand.radius
  const out = [];
  for (let dx = -r; dx <= r; dx++) {
    for (let dz = -r; dz <= r; dz++) {
      if (dx * dx + dz * dz > r * r) continue;
      const wx = centerX + dx, wz = centerZ + dz;
      if (seededRandom(wx, wz, SEED + SKY_TREE_SALT) < SKY_TREE_CHANCE) {
        out.push({ wx, wz, baseY: topY + 1 });
      }
    }
  }
  return out;
}

/**
 * 忠实写入顺序模拟（spec §2.5.1）：按与实现**相同的顺序**逐棵树 generateTree，
 * 后写覆盖（Map.set 天然后写胜）—— 与 makeColumnSetter 的无守卫覆盖语义一致。
 * ⚠️ 这是「世界实际长什么样」的忠实模型，**不是**「每棵树都完整」的理想模型：
 * 实测 21.4% 的树干格被后写树冠覆盖，理想模型的断言必然 FAIL。
 * 返回值：Map<'x,y,z', id>（仅树格，id ∈ {sky_wood, sky_leaves}）。
 */
function simulateIslandTrees(cand, woodId, leavesId) {
  const sim = new Map();
  const setBlock = (x, y, z, name) => sim.set(`${x},${y},${z}`, name === 'sky_wood' ? woodId : leavesId);
  for (const t of expectedTrunkCells(cand)) {
    generateTree(t.wx, t.baseY, t.wz, setBlock, SEED, 'skyTree');
  }
  return sim;
}

/** 对覆盖某岛 AABB（含树冠外扩 2）的每个 column 独立生成，重组为世界坐标 → id */
function reassembleIslandWorld(cand, reg, fn) {
  const centerX = cand.originCx * 16 + 8, centerZ = cand.originCz * 16 + 8;
  const span = cand.radius + 2; // 树冠外扩（spec §2.4）
  const skyCandidates = [computeSkyCandidates(
    Math.floor(cand.originCx / 25), Math.floor(cand.originCz / 25), SEED)];
  const world = new Map();
  for (let cx = Math.floor((centerX - span) / 16); cx <= Math.floor((centerX + span) / 16); cx++) {
    for (let cz = Math.floor((centerZ - span) / 16); cz <= Math.floor((centerZ + span) / 16); cz++) {
      const column = new ChunkColumn(cx, cz);
      fn(column, skyCandidates, reg);
      for (let lx = 0; lx < 16; lx++) for (let lz = 0; lz < 16; lz++) {
        for (let y = cand.bottomY; y <= cand.bottomY + cand.height + 6; y++) {
          const id = column.get(lx, y, lz);
          if (id !== 0) world.set(`${cx * 16 + lx},${y},${cz * 16 + lz}`, id);
        }
      }
    }
  }
  return world;
}

/** 找一个顶层至少有 1 棵树的岛候选 */

    for (const cand of collectIslands(seed, r)) {
      if (expectedTrunkCells(cand).length > 0) return cand;
    }
  }
  return null;
}

/**
 * 找一个顶层圆内**同时**含「随机值略低于阈值」与「略高于阈值」两类格的岛 ——
 * 用于在临界值附近验证判定（M6 教训：用远离阈值的输入测不出阈值写错）。
 * @returns {{cand: Object, topY: number, below: {wx,wz,v}, above: {wx,wz,v}}|null}
 */
function findIslandWithCriticalPair(seed, n = 2, eps = 0.002) {
  for (const cand of collectIslands(seed, n)) {
    const centerX = cand.originCx * 16 + 8, centerZ = cand.originCz * 16 + 8;
    const topY = cand.bottomY + cand.height;
    const r = islandLayerRadius(cand.radius, cand.height, cand.height);
    let below = null, above = null;
    for (let dx = -r; dx <= r && !(below && above); dx++) {
      for (let dz = -r; dz <= r; dz++) {
        if (dx * dx + dz * dz > r * r) continue;
        const wx = centerX + dx, wz = centerZ + dz;
        const v = seededRandom(wx, wz, seed + SKY_TREE_SALT);
        if (!below && v < SKY_TREE_CHANCE && v > SKY_TREE_CHANCE - eps) below = { wx, wz, v };
        if (!above && v >= SKY_TREE_CHANCE && v < SKY_TREE_CHANCE + eps) above = { wx, wz, v };
        if (below && above) break;
      }
    }
    if (below && above) return { cand, topY, below, above };
  }
  return null;
}

 * 几何上不重叠，故层序不影响结果；但保持「岛体先、树后」与 mc-lite 的生成顺序一致
 * （mc-lite 在写岛体格的同一个循环里长树）。
 *
 * ⚠️ **AABB 门控必须比岛体宽 2 格**（spec §2.4，本次最易出 bug 的点）：
 * 树冠从基点向外扩 ±2（`vegetation.js:22-29` 的 lx/lz 循环），故树的水平足迹是
 * `centerX ± (radius + 2)`。若沿用岛体的 `± radius` 门控，会出现「某 column 与岛体
 * AABB 不相交、却有树冠落入」→ 该 column 被 continue 跳过 → **树冠在相邻 column 上
 * 断裂缺角**。方块层面岛体完全正常，肉眼只看到「岛边缘的树缺了一角」，很难归因。
 *
 * 跨 column 逐格一致的保证：判定（`seededRandom(wx, wz, ...)`）与生成
 * （`generateTree` 内部 `treeRand(lx, lz, ...)`）**都只吃世界坐标** → 同一格在任何
 * column 的生成过程中结果完全相同；写入裁剪由 `setBlock`（`makeColumnSetter`）承担。
 *
 * @param {import('../../voxel/chunk-column.js').ChunkColumn} column
 * @param {Array<{skyIslands: Int32Array, cloudClusters: Int32Array}>} skyCandidates
 * @param {number} seed
 * @param {*} registry
 */
export function writeSkyTrees(column, skyCandidates, seed, registry) {
  const setBlock = makeColumnSetter(column, registry);
  const minX = column.cx * 16, maxX = minX + 15;
  const minZ = column.cz * 16, maxZ = minZ + 15;
  for (const { skyIslands } of skyCandidates) {
    for (let i = 0; i < skyIslands.length; i += 5) {
      const centerX = skyIslands[i] * 16 + 8, centerZ = skyIslands[i + 1] * 16 + 8;
      const bottomY = skyIslands[i + 2], radius = skyIslands[i + 3], height = skyIslands[i + 4];
      // 树冠外扩 ±2 → 门控放宽 2（见函数注释）
      if (centerX + radius + 2 < minX || centerX - radius - 2 > maxX ||
          centerZ + radius + 2 < minZ || centerZ - radius - 2 > maxZ) continue;
      const topY = bottomY + height;
      // 树基点落在岛顶层（y === height → 半径恰为 radius，见 islandLayerRadius）
      const r = islandLayerRadius(radius, height, height);
      for (let dx = -r; dx <= r; dx++) {
        for (let dz = -r; dz <= r; dz++) {
          if (dx * dx + dz * dz > r * r) continue;
          const wx = centerX + dx, wz = centerZ + dz;
          // 判定用世界坐标 → 跨 column 同格判定一致
          if (seededRandom(wx, wz, seed + SKY_TREE_SALT) < SKY_TREE_CHANCE) {
            generateTree(wx, topY + 1, wz, setBlock, seed, 'skyTree');
          }
        }
      }
    }
  }
}

// 判据：① 树冠区屏幕像素 == sky_leaves 颜色（不含背景/墙色混合）→ opaque 不混合
//      ② 与 cutout 单变量对照 RGB 基本相同 → 证明改通道视觉零变化
// ⚠️ 不宣称目视（CLAUDE.md：截图的 Read 只返回 URL）；阈值对着屏幕实测值读（M8 教训）。
import { test, expect } from 'playwright/test';
import { PNG } from 'pngjs';

/** 区域主色（取中位数，比均值抗纹理噪点） */
function regionMedianColor(png, x0, y0, x1, y1) {
  const rs = [], gs = [], bs = [];
  for (let y = y0; y <= y1; y++) for (let x = x0; x <= x1; x++) {
    const o = (y * png.width + x) * 4;
    rs.push(png.data[o]); gs.push(png.data[o + 1]); bs.push(png.data[o + 2]);
  }
  const med = (a) => a.sort((p, q) => p - q)[Math.floor(a.length / 2)];
  return [med(rs), med(gs), med(bs)];
}
/** 区域内「接近目标色」的像素占比 */
function colorRatio(png, x0, y0, x1, y1, target, tol) {
  let hit = 0, n = 0;
  for (let y = y0; y <= y1; y++) for (let x = x0; x <= x1; x++) {
    const o = (y * png.width + x) * 4;
    n++;
    if (Math.abs(png.data[o] - target[0]) <= tol &&
        Math.abs(png.data[o + 1] - target[1]) <= tol &&
        Math.abs(png.data[o + 2] - target[2]) <= tol) hit++;
  }
  return hit / n;
}
